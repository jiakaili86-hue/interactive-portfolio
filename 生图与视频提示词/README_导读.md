## 阅读顺序建议

1. 先读 `01`（硬约束，决定能不能交付）。
2. 写关键词前复习 `02`（方法论）。
3. 按需查 `03`（画风）与 `04`（工作流）。
4. 参照 `示例-标准架构` 套项目结构。

## 核心速记

- **生视频默认走「全能参考生视频」**：先上传参考图/视频，提示词正文必须含 `@图片N / @视频N`，与上传顺序一致；除非用户明确说只要纯文。
- **生图默认不主动出 Seedream**：角色只出一张 16:9 三视图总览；道具/场景默认不出图，交给 Seedance 文字描述；用户当次点名才出。
- **每段视频 ≤15 秒**，时间码按真实需要分配，禁止平均三等分占位。
- **默认禁止字幕/屏幕文字/水印**，字幕后期加。
- **用户台词逐字不改**（铁律），需改先问。
- **正向写画面**，少用否定词；多人物先锁前景/中景/远景与朝向再写氛围。
