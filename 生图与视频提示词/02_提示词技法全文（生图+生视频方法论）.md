# 即梦 AI 提示词规则（通用方法论）

> **模型版本**：生图使用 **Seedream 5.0**（即梦图片 5.0），生视频使用 **Seedance 2.0**（即梦视频 2.0）。  
> **本文件定位**：技法与方法论全文。**每次必遵守的硬约束**（章节结构、`@` 必带、单段 ≤15 秒、字幕禁令、道具/场景默认不出图、三视图默认）见 `jimeng-core-delivery.mdc`。**具体画风模版**与**工作流**通过用户口令触发，分别在：  
> - 画风（合集，按口令调用对应一节）：`jimeng-styles.mdc` 内含 A 超写实电影 / B 2D 赛璐璐 / C 搞笑彩绘极简 / D 手绘铅笔速写  
> - 工作流（合集，按场景调用对应一节）：`jimeng-workflows.mdc` 内含 A 分镜图→视频（九宫格）/ B 多段视频延长/硬切 / C 手机自拍 POV / D 真人过审

## 核心原则

即梦理解具象描述，不理解抽象意境。所有prompt必须是**可视觉化**的画面描述。

### 产出语言：视频提示词默认纯中文

- **交付给用户、用于即梦/Seedance 粘贴生成的视频提示词正文**：**默认全中文**，不写 `Subject` / `Camera` / `Cut to` / `Transition to` 等英文标签或英文分镜标记。
- **镜头切换**：优先用 **「切换至」「硬切至」「接」** 等中文；若用户明确要求或实测某版模型仅认英文标记，再单独改用 `Cut to`。
- **运镜**：正文里用 **中文运镜词**（如缓慢推镜、缓慢拉远、横移、环绕、动态跟拍、手持跟拍、稳定器感平滑移动、低角度仰拍、焦点转移、浅景深等）。下文章节中的 **中英对照表** 仅作理解与检索，**不默认复制英文进用户提示词**。
- **@ 引用**：保留即梦产品语法（如 `@图片1`、参考 `@场景图`），算工具语法，不视为「英文描写」。
- **生图提示词**：同样 **默认纯中文**；除非用户指定要英文关键词。
- **所有视频默认无字幕**：Seedance 视频正文默认必须写 **禁止生成字幕、禁止生成屏幕文字、禁止生成标题文字、禁止生成水印**；除非用户当次明确要求画面内文字，否则字幕和标题一律后期添加，不交给模型生成。

### 与「高密度长模版」的关系（避免和项目默认混为一谈）

- **为何和早期给你的出入大**：若某次交付是 **写实电影向 + 默认 16:9 + 纯中文运镜**，而你手里另一条是 **9:16 竖屏 + 日系热血赛璐璐 + Subject/Camera/Scene/Lighting 英文骨架 + 声层**，二者是 **不同画风档位与画幅**，不是「新版本全面替代旧版本」。并线使用时容易互相污染画风，应 **分文件、分镜组** 落盘。
- **对照社区常见「优秀结构」**：多源指南普遍强调 **主体 / 动作 / 环境 / 运镜 / 风格 / 约束**（或七要素）；**镜头运动与主体运动分开描述**；**单条 4–15 秒内用时间码分段**。你贴的模版在这些点上 **与共识一致**，信息密度高时往往更可控。
- **纯中文 vs 英文标签**：本文件默认 **交付正文不写** `Subject` / `Camera` 等英文标签，是为统一中文区粘贴习惯与减少混排噪声。**若你已通过实测确认**「保留英文骨架 + 中文描写」或「全中文同结构」在某一画风下更稳，**可在当次任务中明确要求沿用你的长模版**；助手在对话交付时按你的要求执行，并在项目内注明档位（写实 16:9 / 日系 9:16 等）。
- **哪种「生成效果更好」**：无普适答案——先 **对齐画风与比例**（要什么就从头到尾写什么），再在同一模型版本下 **A/B 对比**。通常 **主运动唯一、时间码清晰、分层（前中景/光/音）** 比「散词堆砌」更稳。

### 外源共识·干净 2D 卡牌角色设计（2025–2026）

- **先定唯一视觉锤**：每张卡只保留 1 个不可丢的记忆点（武器轮廓、发饰、披风外形、特殊姿态等），不要把服装、特效、背景、道具全部平均加戏。
- **先剪影后细节**：角色缩到 128px 仍能认出职业和武器；外轮廓至少有 2 个清晰特征点，头发、武器、披风不要黏成一团。
- **配色按 6:3:1**：主色 60%、辅色 30%、点缀色 10%；高亮只给脸、手、武器核心，不让背景和特效抢焦点。
- **细节密度分区**：脸、胸口、武器可精致；腿部、背景、边框留作视觉休息区。细节到处都是等于没有重点。
- **特效用“少而准”**：只放 1 种主特效形态（火花 / 冰晶 / 电弧等）+ 少量粒子，控制在角色周围局部区域；禁止满屏光效、烟雾、碎片。
- **卡面留白纪律**：标题、费用、属性、技能框周围保持干净色块或低纹理底；背景密度低于角色，UI 面板不被头发、武器、特效压住。
- **自己的画风锚点**：统一使用“粗细稳定的干净线条 + 平滑赛璐璐上色 + 少量柔和渐变阴影 + 大块面配色 + 低噪点”，避免写成通用“精致二次元大作堆料”。
- **提示词先写设计，再写特效**：顺序为“角色性格与视觉锤 → 剪影/姿态 → 服装结构 → 配色比例 → UI 留白 → 少量特效 → 负面去噪”，不要一上来堆“华丽、粒子、爆炸、光效”。

### 外源共识·二游差异化风格拆解（2026）

- **风格不是“画得精致”**，而是一个可重复的母题系统：世界观关键词、角色比例、线条粗细、上色方式、UI 形状、字体气质、背景密度、特效克制度必须互相证明。
- **头部二游各有唯一审美母题**：原神是明亮童话幻想与地域文化；星穹铁道是高精度幻想科幻与舞台式演出；绝区零是都市街头、复古科技、包装设计与涂鸦；鸣潮是成熟灰调、末世自然与凌厉动作；明日方舟是冷峻工业、战术 UI、低饱和与警戒色；重返未来是复古拼贴、神秘学、时代符号；蔚蓝档案是清爽校园、柔和赛璐璐、学生日常与军武反差；边狱公司是暗黑文学、粗粝线条、低饱和与叙事符号。
- **做原创风格时先写“不可替换规则”**：若把角色换成别的职业，仍能看出同一项目；若拿掉特效，仍有独特线条、比例、UI 和配色；若只看卡牌边框，也能认出这个系列。
- **卡牌项目优先建立 4 个统一件**：统一卡框语言、统一角色比例、统一线条与上色、统一背景材质；每张卡只替换职业视觉锤和局部配色。
- **借鉴不要借表面符号**：不要把“街头涂鸦、工业警戒线、复古神秘学、校园军武”直接拼到同一张图；要抽取其底层方法：母题一致、信息分层、视觉锤集中、留白有纪律。

### 外源共识·竽 / 笙类乐器演奏姿势（2026）

- 马王堆一号汉墓奏乐木俑中，吹竽乐俑采用屈膝跪坐 / 跽坐姿态，身着交领右衽长袍；宫廷礼乐队列场景优先写「跽坐在蒲草席上吹竽」，比站立更有古代礼乐感。
- 竽已失传，动作可参考同类笙的演奏法：上身挺直放松，双手托住竽斗，手指自然弧形贴近竹管下段音孔，嘴唇贴住短吹嘴，双颊微收。
- 乐器空间关系要写清：深红漆木竽斗靠近胸前，短吹嘴接到嘴边，高耸竹管束向上并略向右侧倾斜，避免遮住整张脸；长管在内侧 / 中央，短管在外圈。
- 生成三视图时若要求「吹奏动作」，三列都要保持同一吹奏姿势与同一件竽：正视看手位和嘴贴吹嘴，侧视看吹嘴接嘴与竹管倾斜角，背视看管束背面、肩背和宽袖关系。

### 外源共识·挑担 / 卸担动作链（2026）

> 来源综合：扁担力学与民俗资料、搬运安全教程、肩挑工具英文资料。用于 Seedance 写挑担、放下水桶/箩筐/油担时，把“卸下担子”拆成可见的身体动作和物理接触，避免木棍穿脖子、桶悬空或绳子乱飞。

- **核心原则**：卸担先卸重量，再卸扁担。先让两端桶/筐稳稳着地，确认绳子松弛、重量离开肩膀后，才把扁担从承重肩侧移开。
- **站稳再卸**：人物先停步，双脚站开约肩宽，身体正对要放置的位置；不要一边扭腰一边卸。
- **腿部下蹲**：腰背尽量直，膝盖弯曲、重心下沉，用腿带身体下降；不要弯腰猛甩。
- **双手控摆**：至少一只手扶住扁担前段，另一只手扶后段或绳索/桶沿，控制两端晃动。
- **两端先触地**：扁担仍在肩上时，人物继续下蹲，让两只桶/筐先后或几乎同时接触地面；桶底贴地后不再横向滑动。
- **绳子状态**：桶落地前绳子绷紧承重；桶落地后绳子自然松弛垂下，这是判断重量已离肩的关键画面。
- **扁担退出路径**：重量落地后，扁担沿承重肩同一侧向外滑离肩膀，或人物轻抬肩膀让扁担从肩窝旁边离开；扁担不从脖子后穿到脖子前。
- **最终落点**：扁担放在两桶之间或人物脚边地面，保持横向或斜向平放；人物手最后离开扁担。
- **提示词禁区**：不要写“把扁担从脖子后绕到前面”“木棍穿过身体前方”“直接把担子甩下来”；这会诱发穿模。
- **可复制动作链**：`停步站稳，双手扶住扁担和绳索，膝盖弯曲慢慢下蹲，先让两端桶底接触地面，桶落地后绳子从绷紧变成自然松弛，确认重量离开肩膀，再把扁担沿承重肩外侧平稳滑离肩膀，放到两桶之间的地面，双手最后松开。`

### 外源共识·足球动作视频描写（2026）

> 来源综合：足球教练技术拆解、动作摄影、射门生物力学、动画 body mechanics 与足球术语库。用于写 Seedance 足球视频时，把“会踢球”改成可视化动作链，避免只写“盘带很帅 / 大力射门 / 精彩过人”。

- **动作链顺序**：先写准备姿态与重心，再写支撑脚位置、触球脚部位、身体旋转、球的轨迹、随摆收势。例：`左脚支撑在球左侧半步，脚尖指向球门，右腿后摆，髋部带动大腿前摆，脚背正面击中足球中心，右腿顺势向前随摆`。
- **盘带**：写清触球频率、触球部位和球距身体的距离。可用 `小步高频触球`、`外脚背轻拨`、`内脚背扣回`、`脚底踩球停顿`、`球始终贴近脚前一小步`。
- **变向 / 假动作**：用“假动作诱导 + 真动作摆脱”的两拍结构。例：`肩膀先向右沉一下假装内切，防守者重心被带偏，随后左脚外脚背把球拨向画面左侧空当`。
- **急停卸球**：写“减速、触球、身体缓冲”。例：`球滚到脚前，球员脚底轻踩球面把球停住，膝盖微屈吸收速度，身体重心从前冲变成低位稳定`。
- **传球**：短传写 `内脚背推传，脚踝锁住，支撑脚指向接球队友，球贴地直线滚出`；长传写 `身体后仰少量，脚背下方挑起球底，球离地形成弧线飞向远端空当`。
- **射门**：必须写支撑脚、髋肩旋转、击球点和随摆。低平射用 `身体压在球上方，脚背击中球中心偏上，球贴草皮高速直线冲向门角`；兜射用 `脚内侧包住球侧面，脚踝锁紧，随摆向内卷，球划出弧线绕向远角`；凌空抽射用 `膝盖微屈，身体正对来球，球下落瞬间脚背迎上击球，随摆穿过球的飞行线`。
- **倒挂金钩 / overhead kick / bicycle kick**：这是高难度腾空倒钩，不要凭“帅气后仰踢”硬写。标准动作链：球员背对球门，眼睛盯住空中来球；击球脚先留在地面作为起跳脚，非击球腿先向上猛摆带起身体；头肩和上身向后倒，腰背后仰到接近与地面平行；空中双腿做剪刀式交换，非击球腿向下落，击球腿向上鞭甩；用脚背 / 鞋带部位击中空中足球，球从头顶方向向身后球门飞出；双臂张开准备缓冲，落地时侧身滚落，避免平背或头颈着地。视频里峰值抓 `身体横在空中 + 双腿剪刀形 + 击球脚刚触球`。
- **头球**：写清起跳、颈部发力和球离头距离。例：`双脚蹬地起跳，背部微微后弓，眼睛盯住来球，额头正面迎球，颈部短促前甩把球顶向球门`。画面里球要靠近额头，不能离头太远。
- **防守动作**：站立抢断写 `侧身降低重心，前脚探出，脚尖从对手触球线路前方把球捅走`；滑铲写 `身体侧向贴近草皮滑行，近端腿伸直用脚内侧先碰到球，另一条腿弯曲收住，避开对手支撑脚`。
- **冲刺与无球跑动**：写 `身体前倾、手臂前后摆动、步幅拉长、脚掌前部快速蹬地`；接球前加 `转头扫描身后、打开身体朝向球和进攻方向`，比只写“快速跑位”更稳。
- **守门员扑救**：写 `蹬地脚、身体伸展方向、手掌接触球、落地缓冲`。例：`门将右脚蹬地横向飞扑，身体在空中伸展，双手手掌迎向近门柱方向的来球，指尖把球托出底线，落地时肩背先触地滚动缓冲`。
- **镜头峰值**：足球动作最适合抓“触球前一瞬 / 触球瞬间 / 球刚离脚”三类峰值。动作摄影资料强调峰值画面要有球、表情和肢体张力；提示词中尽量把球放在脚边、额头边或手掌边，避免球离主体太远。
- **一镜一主动作，分镜从少开始**：单条视频里只保留一个主要技术动作（一次射门、一次扣球、一次传中、一次扑救）。足球 / 热血运动类视频 **优先 2 个分镜**，动作确实需要才扩到 3-4 个；15 秒内最多 4 个分镜。不要为了显得电影化把同一动作拆碎，切镜越多越容易角色位置和球路漂移。
- **视频交付模板**：凡是足球类 Seedance 视频提示词，默认调用 `jimeng-workflows.mdc` → Step 4.5「连续故事视频关键词新模板」（基调 + 分镜时间 + 景别 + 构图 + 运镜手法 + 画面内容）。足球动作链只写进「画面内容」；「构图」只写首帧静态站位、球的位置、人物朝向和空间层级；「运镜手法」只写镜头如何跟拍 / 推近 / 横移 / 定格，不写动作结果。
- **减少配角复述**：配角/怪物只在需要交代空间关系和动作结果的分镜里出现一次，不要每段反复写名字和状态。若主角已摆脱配角，后续只写主角继续动作，配角最多作为远处背景结果一笔带过。
- **参考图做减法（硬约束）**：凡 `@图片` 里已经体现了角色样貌、服装、道具或行为姿态，视频提示词里不要复述这些已锁信息；基调只写 `严格参考@图片N保持该角色一致`。只有需要修改参考图没有体现的动作、情绪、位置关系时，才在对应分镜里补写。
- **俯视点位场景图**：需要用 image 生成足球场点位图时，默认按 FIFA 常用职业球场比例 **105m x 68m** 做完整全场俯视横版，不用 9:16；图中只放小红圈数字点位，不画球员、足球、箭头和路线。视频基调里只写一句 `@图片N是足球场俯视点位示意图，仅用于锁球场空间和点位编号`，不要在基调解释“谁在几号点干嘛”；人物、跑位、传球、射门和点位编号只放到各分镜的「构图 / 画面内容」里写。

### 外源共识·热血青春运动番表现力（2026）

> 来源综合：《排球少年》制作/分镜分析、运动番评论、蓝色监狱制作访谈、动画微表情与运动情绪资料。用于足球、篮球、排球、田径等热血青春运动类 Seedance 视频。交付时仍默认调用 `jimeng-workflows.mdc` → Step 4.5「连续故事视频关键词新模板」。

- **现实动作 + 动画情绪**：先用真实运动技术锁身体力学，再在爆点处允许动画化夸张：拉伸脚掌、速度线、冲击帧、气流、短暂变形、背景抽象化。不要全程都夸张，现实段越稳，爆点越燃。
- **三段节奏**：运动番常用 `蓄力安静 → 动作爆发 → 情绪回落`。写时间码时不要一路快：先给 1-2 秒呼吸、眼神、握拳或脚步准备，再突然加速，最后留 0.5-1 秒看表情或球的结果。
- **微表情优先级**：热血不是只喊叫。关键微表情包括：瞳孔收缩、眼神从动摇变坚定、嘴角绷紧、牙关咬住、眉头压低、汗珠滑过脸颊、呼吸急促、喉结吞咽、短暂停住后重新抬眼。
- **镜头情绪链**：先拍身体局部，再拍眼神，再拍动作全貌。常用连接：`脚尖踩地特写 → 眼睛近景 → 低角度跟拍冲刺 → 球离脚瞬间慢动作 → 队友/对手反应特写`。
- **主观视角**：需要代入感时，用球员 POV 或对手 POV：球门突然变窄、对手像墙一样压近、传球路线像光线一样打开、时间短暂变慢。主观镜头只用于关键判断，不要整段滥用。
- **故事感来自“前后反应”**：一个动作前必须有心理或局势压力，一个动作后必须有人反应。例：射门前写“他听见队友喘息和防守脚步逼近”；射门后写“门将指尖擦过球，队友屏住呼吸，对手回头追看球轨迹”。
- **群像运动的焦点纪律**：多人同场时只给一个主角动作，其余人做压迫、等待、补位、转头、伸手示意或失衡反应；避免多人同时复杂动作导致画面乱。
- **情绪外化要有理由**：可写专属气场、速度线、碎片化视野、球路光线、黑场聚光、背景消失，但必须对应角色心理：觉醒、恐惧、孤注一掷、突破瓶颈、看见空当。不要无理由满屏特效。
- **切镜承接**：动作切镜要靠运动方向承接。上一镜球向画面右侧飞，下一镜开头也让球从画面左侧进入；上一镜人物向前冲，下一镜用脚步/衣摆/头发继续同方向运动，避免跳位。
- **慢动作用在峰值**：慢动作只放在起跳最高点、触球瞬间、球刚离脚、指尖将碰到球、眼神决定的一拍。普通跑动不要慢动作，否则节奏塌。
- **声音与情绪同步**：可写鞋钉摩擦、急促呼吸、衣料甩动、球被击中的闷响、观众声瞬间压低、心跳声一拍。BGM 不默认生成；声音只服务动作与情绪。
- **失败也要燃**：运动番不只写成功。可以写 `全力起跳却差一指距离`、`射门被扑出但主角笑了一下`、`摔倒后手掌撑地立刻抬头`，让故事有成长感。
- **连续故事模板落位**：在 Step 4.5 字段中，`基调`写青春热血运动番、队服和情绪母题；`景别`写近景/低角度/主观视角等；`构图`只写首帧站位与球的位置；`运镜手法`写推近、跟拍、甩镜、慢动作、焦点转移；`画面内容`写微表情 + 足球动作链 + 反应镜。
- **分镜数量上限**：热血运动类 Seedance 视频 **15 秒内最多 4 个分镜**。若动作链很多，合并成同一分镜内的连续动作，不再拆成 5-6 个分镜；宁可让每镜 3-5 秒讲清位置、球路和情绪。

### 外源共识·先秦题材历史考据要点（2026）

> 来源综合：《礼记·礼器》《周礼·弁师》《韩非子·内储说上》《战国策·齐策》《仪礼》《周礼》相关条目，临淄齐故城/稷下学宫考古报道，青铜纹饰断代资料，幞头与巾帻服饰史资料，竽/笙考古与乐器史资料。用于滥竽充数、卖油翁等先秦/秦汉成语故事动画的服化道关键词，避免观众挑出「历史常识性错误」。

- **故事与城市背景**：滥竽充数出自《韩非子·内储说上》，齐宣王「使人吹竽，必三百人」，齐湣王「好一一听之」。齐国都城为临淄，战国田齐时期经济与音乐文化繁盛，可写「临淄宫廷」「齐国大殿」「乐师众多」，不要写成秦汉长安、唐宋宫城或明清紫禁城。
- **宫殿空间**：齐故城/稷下学宫考古显示战国齐国高等级建筑可用「封闭院落、成排宫殿式夯土基址、高门大屋」口径。画面写朱红漆木立柱、夯土高台、漆木屏壁、青铜鼎/立灯、苇席坐垫、低矮几案；木构写粗木柱、简洁梁枋、栌斗/曲木挑梁雏形即可，禁止成熟唐宋明清式多层繁复斗拱、明清金銮殿、雕龙宝座、高背椅、石狮、御道龙纹丹陛。
- **宫廷附属院落 / 乐师住处**：若写宫廷乐师居住、候命、练习的地方，不要写现代宿舍、后世客栈或市井店铺；可写「宫城附属封闭院落、成排低矮夯土房基、粗木柱廊庑、简洁木门、黄褐夯土地面、陶瓦屋面、木栅、少量陶罐/竹筐」。空间应比正殿朴素，廊下空旷、无人、无店招、无文字，仍保持战国土木混合结构与几何纹简饰。
- **坐具铁律**：战国为席地跪坐时代。君主写「低台 + 坐席/矮榻 + 漆木几案」，乐师写「跪坐/端坐于苇席上」，双膝屈地、臀部坐在脚跟上；禁止垂腿坐椅、沙发、板凳、高背王座。几案只在君王或宴饮案前保留，吹竽乐师面前通常不放高桌，避免乐器与桌子穿模。
- **交流礼仪**：先秦正式相见多用揖礼、拜礼，宫廷中臣子/乐师面对君王可写「拱手作揖、躬身行礼、低头候命、跪坐听令」。不要写清宫式三跪九叩、甩袖打千、太监宣旨；群体行礼可写「众乐师一齐俯身作揖」。
- **冕旒等级**：周礼口径为天子十二旒、诸侯九旒、上大夫七旒、下大夫五旒。战国称王的诸侯（齐宣王、齐湣王）写 **九旒** 最稳；「七旒」出自汉制（三公诸侯七旒），属拿汉制套先秦，可接受但非首选。禁止给齐王写明清式平天冠、十二旒天子冕、珠帘过密到清代戏曲感。
- **君王服饰**：齐宣王/齐湣王可统一为玄黑宽袖交领右衽冕服、赭红下裳、蔽膝、玉组佩、云雷纹/回纹镶边。齐国服饰可偏华丽，写「锦边、云纹、错采镂金的装饰感」即可；禁止明清团龙袍、五爪金龙、补子、朝珠、马蹄袖。
- **齐湣王角色区分**：齐湣王田地为齐宣王之子，前301年继位，在位十七年，曾与秦昭襄王并称东帝/西帝、灭宋，后因骄横刚愎、穷兵黩武、拒谏离心，前284年五国伐齐后出逃被杀。角色设计应与齐宣王同服制体系（九旒冕、玄衣纁裳、玉组佩），但气质更年轻、更锐利、更自负：眉形上挑、眼神审视、下颌更瘦、笑意收敛，避免画成慈祥富态版齐宣王。
- **普通乐师服饰**：南郭先生与乐师宜穿浅灰、米白、褐色麻布深衣或短一些的交领袍服，窄袖便于抱竽，腰束布带，草鞋/布履。庶民首服用露髻束发插簪、贴头小冠、布巾裹头；幞头/软脚垂角帽起源北周，先秦题材禁止使用。「帻」严格说起于战国末秦军、盛于汉，慎用，写「布巾裹发」更稳。
- **竽的形制与动作**：竽是比笙更大的簧管吹奏乐器，常见文献说三十六簧，也有二十二/二十三管考古形制；画面应是竽斗/匏斗或木漆斗上插多根长短不一的竹管，双手抱持竽斗，口含吹嘴或贴近吹嘴，身体微微前倾。禁止画成横笛、唢呐、葫芦丝、现代排箫；南郭装样子时写「腮帮不鼓、嘴唇轻贴吹嘴、眼神偷瞄旁人、手指随众人乱动」。
- **宫廷乐队调度**：先秦礼乐有「升歌/登歌」与「下管」空间区分，歌者在堂上，匏竹管乐（笙竽类）在堂下，用位置体现「贵人声」。滥竽充数写齐王听竽时，最稳空间是「齐王在堂上/高台跪坐听乐，三百吹竽乐师在堂下庭院或殿前低处成排演奏」。如为了镜头可读性把乐师放进同一大殿画面，必须写成殿下/堂下低处、明显低于齐王高台，不要写成与君王同层的封闭室内坐席。三百人不要真的全画清脸，用「前景 5-8 名乐师 + 中景多排乐师 + 远景密集坐席」表达规模；独奏规则出现时只让一名乐师到堂下中央空地或高台前，其余人退到两侧等待。
- **侍卫与随从**：若出现宫廷侍卫，用战国皮札甲/髹漆皮甲、短胄、革带、戈戟/剑，颜色赤黑或深褐；禁止唐宋明清甲胄、圆翅官帽、满清侍卫顶戴。侍从可以穿深衣、束带、拱手侍立，不要出现太监、宫女清装或明清官服。
- **纹样断代**：饕餮纹（兽面纹）、夔纹盛行于商至西周早期，战国已退居辅助；战国宫殿背景首选蟠螭纹、蟠虺纹、勾连云纹，云雷纹做地纹全期安全。但生图时「蟠螭/蟠虺」容易触发大龙壁画，若模型常画错，改写为「抽象几何卷曲连续纹样、青铜器表面的细密回旋花纹」，并集中写禁令：禁止龙形图案、动物形象壁画。
- **通用自检**：先秦题材交付前扫一遍——城市时代、坐具坐姿、行礼动作、冕旒数、服装纹样、乐器形制、乐师队列、侍卫甲胄、墙面纹样、画面文字禁令是否都对得上战国断代；同片多位君主（齐宣王/齐湣王）服制风格须一致，只通过年龄、神态和气质区分。

### 外源共识·忧郁暗黑风格化角色插画（2025–2026）

> 检索摘要：2026 插画趋势（反完美/手绘痕迹）、暗黑氛围插画技法拆解、低饱和色家族肖像方法论、都市孤独感插画语法等多源交叉。适用于忧郁/暗黑/孤独感的风格化角色生图与原创画风设计。

- **受控粗糙（controlled roughness）**：反完美、可见笔触是「人画的」信任信号，但糙只放在轮廓与边缘（干笔刷断笔、磨损毛边），内部保持平滑纯色，不堆纹理滤镜；「外糙内净」反差本身即风格记忆点。
- **低饱和色家族选色**：忧郁暗黑配色按色家族而非单点选色——炭黑棕、暗栗红、石板灰、灰绿、低饱和奶油白（「氧化的暖」）；皮肤偏苍白带灰、忌红润；忌高饱和大红大绿。
- **暗部吞噬法**：暗部压至近纯黑，可让人物局部（下半身/衣摆）溶进黑暗；亮色与跳色合计占比 **≤10–15%**，只点在关键位置，占比一超压抑感即失。
- **虚实对冲**：主体清晰、背景抽象/虚化；冷调背景约 70%、主体亮部约 30%，形成「视觉锚点 + 氛围」双层。
- **孤独感构图语法**：大负空间（人物偏置或缩小、头顶留空）+ 一两个具体情绪锚点道具（雨夜、空椅、路灯、窗、烟、地铁），比堆氛围形容词有效。
- **克制的悲伤**：眼神半垂/空洞、嘴角微抿，避免夸张哭泣；情绪浓度靠姿态（低头、微驼、手插兜）与留白，不靠表情夸张。
- **剪影优先 + 缩略图测试**：大而有表达力的剪影比复杂渲染更承载情绪；所有风格设计须在缩略图尺度仍可辨认才成立。
- **原创性 = 通用语法 + 私有符号锚点**：防同质化靠植入一两个贯穿全部作品的固执符号（如全图黑白灰仅一处红色、不对称竖线眼、无脖嵌脸剪影），通用氛围技法人人会用，私有锚点才是签名。
- **风格收敛流程**：一个受限 moodboard + 三个剪影变体 + 一套六色色板系统，缩略图尺度反复测试，先锁色板与剪影再谈细节。
- **抽象度分层**：要「抽象但看得出是正常人」时，人物本体画实（发型、衣着层次、手、可读表情），抽象感放到氛围层（背景抽象笔刷色域、暗部吞噬局部、非现实跳色），不靠省略人体。

### 外源共识·小红书爆款美术 IP 绘画逻辑（2025–2026）

> 检索摘要：Labubu/Chiikawa/Molly/顽顽崽等高互动 IP 的设计拆解、设计师访谈、日方画法解析、IP 设计趋势文多源交叉。适用于原创 IP 角色设计与画风定调。数据锚点：小红书「丑萌 IP」笔记半年增长 470%；极简风头部授权占比 15%→42%；高级感 IP 生命周期比纯可爱型平均长 2.3 年。

- **幼态几何底盘可计算**：治愈系爆款头部 = 纵长椭圆（长短轴约 1.5:1），身体 = 圆筒，头身比 1:1~1:2；五官重心低于面部中线并向中央聚拢（幼态无辜感）；四肢省略手指、画成圆润短柱（细长四肢有成人感/攻击性）；同 IP 角色脸模板化，胖瘦只调身体宽度。
- **反差签名「分区冲突」**（Labubu 配方）：上半脸全萌系信号（大眼、水汪瞳仁、腮红），下半脸埋一处怪系信号（9 颗锯齿尖牙）；反差元素只能有一处且被大面积萌系包裹——「多一分怪异失亲和，多一分可爱失独特」。
- **签名要「可数」**：9 颗牙、3 组 3 这类可数特征让用户能复述、能鉴定、能二创，传播力远强于模糊的「画风可爱」。原创 IP 必须有至少一个可数的固执特征。
- **幼态化参数能救活怪物底子**：Labubu 初代（方脸细眼长肢）无人问津，爆款版 = 脸拍圆 + 眼瞳放大 + 身体压扁变短 + 加腮红，怪物设定不变。
- **表情「不纯粹」原则**：爆款表情都是混合情绪（天真眼 + 狡黠笑；无奈 + 嘲讽；半闭眼 + 似笑非笑），甚至减到歧义（去嘴只留眼神 =「像在照镜子」）；IP 是情绪容器，表情留白给用户投射，不替用户表演情绪。
- **表情状态机极简**：表情切换只靠嘴/眉弧线曲度，眼睛基本不动；人人能临摹 = 表情包二创裂变的前提；构图须预留配字空间，画面过满杀死二创。
- **粗轮廓线是容错机制**：粗外轮廓让歪斜线条不违和，把手绘抖动包进风格；「故意的潦草/怪诞」（互联网美学）二创传播力可远超精致软萌。
- **上色两极分化**：治愈系 = 低饱和 + 大留白（投射空间）；发疯系 = 高饱和多巴胺撞色（宣泄）；中间地带最危险。高级感减法可狠到只留黑白灰 + 一抹砂色（案例：砍 60% 颜色后小红书自然曝光提升 3 倍）。
- **2026 造型风向从圆到角**：利落直线替代圆滑曲线（棱角脸、修长四肢、疏离克制表情）；丑萌与高级感两头增长，标准甜美可爱被挤压；「宁愿丑到被骂，不能平庸到没人记住」。
- **人格先行**：新 IP 先定人格标签（如敏感/嘴硬/真诚），造型为人格服务；运营上 IP 要成为「嘴替/社交货币」，设计阶段就考虑表情包、盲盒姿态、二创入口。

#### 减少崩坏（与本文其它防崩条叠加）

- **正向约束写进正文**：社区多强调 Seedance 侧以 **「维持面部与服装一致、无畸变、结构正常、画面稳定」** 等 **正向句** 为主；即梦高级设置里的 **负向词可作补充**，不要只靠负向。
- **一镜一主运动**：同一镜头里 **少堆多个激烈动词**，避免轨迹打架导致形变。
- **人物数量**：单条内 **1～2 人** 更稳；多人易脸混、肢体穿帮。
- **动作措辞**：难镜头优先 **缓慢、连贯、自然**；极快打斗拆 **多条短生成** 或 **快切分镜 + 每镜动作单一**。
- **迭代**：构图对、动作不对 → 先只改 Camera；晃 → `handheld` ↔ `gimbal`/稳定器感；手脸反复崩 → **近景改中景** 或减少手部特写占比。
- **时长策略**：先 **4～7 秒或单镜** 试稳，再延长或接下一镜（与上文「先短后长」一致）。

#### 增强表现力（提示词结构）

套用在万能公式上：**主体 + 动作 + 场景 + 光影 + 运镜（含速度）+ 风格锚 + 画质 + 正向约束**；**音效/情绪** 写入画面句（原生音画同步）。多镜头优先用 **「切换至」「硬切至」** 或 **「第N秒–第M秒」节拍**；避免一大段只有形容词无镜头。（**默认产出纯中文**，见「产出语言：视频提示词默认纯中文」。）

#### 外源共识·Seedance 质感提升关键词（2025–2026）

> 来源综合：Seedance 2.0 中文教程、GitHub 提示词合集、海外 prompt guide 与社区实测。核心共识是：**光源方向、空间层次、单一主运镜、焦点行为、材质物理反馈** 比空泛的“高级感 / 电影感”更能提升画面质感。交付时仍默认中文表达，英文术语只作理解参考。

- **先写光，再写美**：每条视频至少给一个明确光源方向和性质，如 `暖金色侧逆光勾出人物轮廓`、`窗外柔和散射光从画面左侧进入`、`画面内台灯作为可见光源照亮桌面和脸部`。不要只写“高级光影”。
- **三层空间法**：用 `前景虚化物 / 中景主体 / 远景环境锚` 替代“层次分明”。例如 `前景是虚化树叶轮廓，中景人物清晰，远景窗外城市灯点形成散景`。
- **一镜一个主运镜**：同一镜头只选 `缓慢推近 / 缓慢拉远 / 横向跟拍 / 环绕 / 升降揭示 / 固定机位 / 手持微晃` 之一；多运镜叠加会增加抖动、变形和焦点漂移。
- **焦点行为提升层次**：可用 `浅景深背景虚化`、`焦点从前景物件转到人物眼睛`、`人物清晰背景柔化`；复杂镜头只写一次焦点变化。
- **真实来自“不完美细节”**：写实真人可加 `轻微胶片颗粒`、`空气中细小浮尘被逆光照亮`、`雨水/雾气/玻璃反光`、`衣料随身体动作自然牵动`，比“超清无瑕”更像实拍。
- **物理反馈要落到材质**：金属写反光方向，布料写褶皱和惯性，皮肤写自然纹理和柔和高光，水面写波纹和反射，卡通 3D 写圆润造型、柔边阴影、玩具/黏土/搪瓷般干净材质。
- **写实真人质感锚**：可选 `超写实实拍真人`、`35毫米电影质感`、`自然肤色`、`真实皮肤纹理`、`轻微自然皮脂微光`、`柔和侧光`、`轮廓光分离人物和背景`、`浅景深散景`。避免 `完美皮肤 / 零毛孔 / 玻璃肌 / CGI感 / 蜡像感`。
- **3D 卡通质感锚**：可选 `皮克斯式3D动画电影质感`、`圆润柔和几何造型`、`柔和全局光`、`干净柔边阴影`、`材质略带玩具般微光泽`、`大色块环境`、`表情夸张但动作有重量`。避免和真人词混写：`真实毛孔 / 写实摄影 / 赛璐璐描边 / 平涂`。
- **画质后缀不只写 4K**：至少补 `画面稳定、动作流畅自然、细节清晰、面部稳定不变形、无模糊、无闪烁、背景稳定、禁止生成字幕、禁止生成屏幕文字、禁止生成标题文字、禁止生成水印`。
- **提示词长度克制**：把最重要的主体、动作、光源、运镜放前面；长达 13–15 秒或多节拍视频用时间码分段，不把多个剧情动作塞成一整句。

**高频短锚（按需择 3–5 条，不整串堆满）**：`暖金色侧逆光`、`柔和窗光`、`画面内可见光源`、`体积薄雾`、`浅景深背景虚化`、`前景虚化遮挡`、`焦点从前景转到人物眼睛`、`轻微胶片颗粒`、`空气浮尘被逆光照亮`、`衣料自然牵动`、`湿润地面反射光`、`轮廓光分离主体和背景`、`稳定器感平滑移动`、`手持微晃纪录片质感`。

#### 不同剧情节奏（把控要点）

与本文 **「剧情类型画面配方」「影视表现力技法库」** 对照使用；Seedance 下额外注意 **单条时长上限** 与 **切镜标记**：

| 类型 | 节奏与镜头 | Seedance 侧注意 |
|------|------------|-----------------|
| **悲剧 / 压抑** | 慢推、固定、远景留白、长一点静场；配乐渐弱 | 单镜动作少、动词舒缓；避免同条再塞快节奏打斗 |
| **喜剧 / 反差** | 节拍停顿、反应镜给足时长；可静镜配荒诞动作 | 台词镜 **≥4 秒** 嘴型与表情；声画可陡变制造笑点 |
| **打斗 / 燃** | 快切、短镜、蓄力→爆发→余韵；速度线、冲击帧、声画陡升 | **勿单条塞满长打戏**：拆多条或每镜只写一个打击/位移；参考视频片段只截取 **关键运镜** |
| **对话 / 日常** | 中景为主、正反打交替 | 最稳景别；运镜用微推或固定 |

## 电影级画面归纳(多源互补 · 与本文技法库合并使用)

> **用途**：把「现代电影画面细节、人物情绪、不同调性的冲击力」收敛成可执行的写法，与上文 **万能公式**、下文 **影视表现力技法库 / 剧情类型画面配方** 叠用，避免只靠空洞形容词或与「一镜一主运动」打架。  
> **外源参考（2025–2026，交叉阅读）**：[Seedance 2.0 使用指南](https://redreamality.com/cn/blog/seedance-2-guide/)（公式、运镜表、@、中文多镜头例）；电影情绪与构图向 [Filmmakers Academy · Camera & Emotion](https://www.filmmakersacademy.com/blog-camera-emotions-techniques/)；AI 提示分层向 [VO3 · 5-layer framework](https://www.vo3ai.com/blog/the-5-layer-prompt-framework-behind-cinematic-ai-video-and-how-to-use-any--2026-03-31)；「像 DP 一样下指令」向 [Directing AI Like a DP (2026)](https://www.garageproductions.in/directing-ai-like-a-dp-creative-techniques-to-make-ai-generated-visuals-feel-cinematic-in-2026/)。**即梦客户端能力以当前版本为准。**

### 结构化写法（叠在万能公式上）

写每条视频 prompt 时，除 **主体+动作+场景+光影+运镜+风格+画质+约束** 外，可内心按下面 **四字段** 自检（与多平台「分层提示」一致，便于写满细节又不乱）：

| 字段 | 写什么 | Seedance 侧注意 |
|------|--------|-----------------|
| **Subject** | 谁、外貌与材质、持物、情绪状态（可见的） | 主体放前、描述可画；与 `@三视图` 对齐 |
| **Camera** | 景别 + **一种主运镜** + 角度 + 可选焦段感/景深 | 同镜避免堆 3 个以上机位指令；激烈用短跟拍+切镜或拆条 |
| **Scene 分层** | 前景/中景/远景各 1 个**叙事道具**或环境反馈 | 用分层替代「很美很大」 |
| **Light & Audio** | 主光方向、轮廓光/体积雾、冷暖对比；音效/BGM **写进画面句** | 利用音画同步；台词段落给足停留 |

**时间轴**：长镜头或单条多节拍时，用 `[0-3s]…[3-7s]…` 或「第一个画面…第二个画面…」写清 **先后**，避免静态摆拍一句到底（与 redreamality 中文古风多镜头示例同型）。

### 节奏总纲：慢与快怎么分工（全片不要只有一种速度）

| 段落功能 | 节奏 | prompt 里怎么写 |
|----------|------|----------------|
| **建立世界 / 史诗感** | 偏慢 | 大远景、缓推、体积雾/烟尘、环境声铺底 |
| **对峙 / 蓄力** | 慢—中 | 固定或微推、眼神与手部细节、配乐渐强 |
| **爆发 / 打斗 / 追击** | 快而短 | Tracking、速度线、环境碎裂/尘土冲击；**单镜一个打击** 或 **拆多条** |
| **反应 / 喜剧** | 慢下来 | 反应时长 > 事件时长；见下文「反应镜头法则」 |
| **揭示 / 台词** | 慢 | 中近景、推近、关键句处 BGM 收束留白 |

**原则**：**慢**用来让观众看清 **情绪与信息**；**快**用来给 **危险与力量感**。与本文「高速冲击镜短、建立镜长」「一镜一主运动」一致：冲击力来自 **节拍+环境反馈+声画陡变**，不是一句话堆十个动词。

### 人物情绪：从「形容词」到「可见清单」

除下文 **微表情与神态 / 肢体配合** 外，写电影感时补三层：

1. **关系与光位**：谁占亮区/谁落在阴影里、机位高低（仰拍/俯拍）暗示权力。  
2. **分步表演**：同一情绪 2～3 步递进（愣住→眼神变化→嘴角变化），用短句时间轴写在 prompt 里。  
3. **道具锚手**：手持物降低手型崩坏概率（与「人物姿势防崩」一致）。

### 调性冲击力速查（光 + 材质 + 运镜 + 声画）

写「残酷 / 华丽 / 科幻 / 可爱 / 恐怖 / 仙侠古风」时，**至少选满 3 类词**：光源性质、材质/环境反馈、一种主运镜、一层声音。

| 调性 | 光与色 | 材质与环境 | 运镜与节奏 | 声音倾向 |
|------|--------|------------|------------|----------|
| **残酷 / 冷硬** | 硬光、顶/侧光、低饱和、青灰阴影 | 暗血褐渍、泥污、金属划痕、粗糙石面 | 固定或冷峻横移；短促打击 | 闷响、刮擦、远处低频 |
| **华丽 / 史诗** | 逆光轮廓、体积光穿尘/雾、金边高光 | 织物高光、珠宝火彩、抛光金属（点到为止） | 慢推、大范围缓移、远景小人对比 | 管弦渐强、钟声、空间回响 |
| **科幻 / 赛博** | 霓虹反射、屏幕蓝光、扫描线、雨面反射 | 玻璃幕墙、拉丝金属、全息发光线条（少写字） | drone 感横移、跟拍、Rack Focus | 电子蜂鸣、雨声混底噪 |
| **可爱 / 治愈** | 柔光、窗光、高明度低对比、浅景深光斑 | 圆润轮廓、毛绒、奶油/马卡龙色（控饱和防塑料） | 慢、圆、固定或微推 | 轻快高频音色、轻环境声 |
| **恐怖 / 悬疑** | 负空间、只照亮局部、闪烁 practical 光 | 走廊纵深、门框剪影、雾 | 慢推后骤停；手持慎用 | 静→噪→一声刺入 |
| **仙侠 / 古风** | 月光冷边、雷光频闪、丁达尔、水面反光 | 广袖滞后、绸缎高光、符纸灰、阵纹地裂 | 对峙慢推、爆发短跟拍、Reveal 拉远见全貌 | 剑鸣、雷滞后、山谷回响 |

**仙侠特例**：把「仙气、意境」落成 **可见元素**——灵力写成 **符文链亮起→碎成光屑**；剑气写成 **青白弧光拖尾+地面石屑被风压推开**；不要单写「很厉害的氛围」。

### 色彩叙事与色调心理学（外源交叉·电影色彩学 + AI 视频色彩控制）

> **外源交叉**：百度百科·电影色彩；人人文库·色彩心理学与情感反应研究（2026）；影视工业网·调色心理；AI 视频提示词色彩控制最佳实践。

色彩不只是"好看不好看"，是和景别、光线并列的**第三叙事语言**。写提示词时"色调/色温/饱和度"不是装饰词，是情绪开关。

#### 冷暖色调 → 心理效果

| 色调 | 心理效果 | 典型场景 | 提示词写法 |
|------|---------|---------|-----------|
| **暖色调（橙黄琥珀）** | 亲切、柔和、舒适、怀旧、浪漫 | 回忆、告别、温馨日常、黄昏 | 「画面整体暖橙色调，色温偏暖黄」 |
| **冷色调（蓝灰青）** | 冷静、疏离、不安、压抑、科技 | 孤独、对峙、悬疑、未来科幻 | 「画面整体冷蓝灰色调，色温偏冷」 |
| **高饱和暖色** | 活力、热情、欢快、童话 | 喜剧、亲子、节日、3D卡通 | 「明快高饱和色彩，色彩鲜明但不刺眼」 |
| **低饱和/去饱和** | 沉重、忧郁、写实、纪实 | 战争、悲剧、回忆闪回 | 「低饱和度色调，画面整体偏灰偏淡」 |
| **单色调（单一色相主导）** | 统一、风格化、情绪沉浸 | 艺术片、梦境、回忆 | 「整体画面被[某色]笼罩，其余颜色退为灰调」 |

#### 互补色与对比 → 视觉冲击

| 配色策略 | 效果 | 提示词写法 |
|---------|------|-----------|
| **互补色对比（橙蓝/红绿/紫黄）** | 强烈视觉冲击、对立、冲突 | 「暖橙色火光与冷蓝色天空形成鲜明色彩对比」 |
| **类似色和谐** | 统一、舒适、无冲突 | 「蓝绿色系为主的和谐色调」 |
| **高对比度** | 张力、戏剧性、力量感 | 「高对比度画面，亮部极亮暗部极深」 |
| **低对比度** | 梦幻、柔和、朦胧 | 「低对比度柔和画面，明暗过渡轻微」 |

#### 饱和度 → 注意力分配

- **高饱和**：抢夺注意力、强化戏剧冲击、适合3D卡通/喜剧/热血
- **低饱和**：让观众聚焦人物表演本身、适合悲剧/纪实/沉思段落
- **局部高饱和**：全画面低饱和中只有一个元素高饱和（如红色围巾/血迹），引导视线到关键信息

#### 色彩转场 → 情绪切换

在多段视频中，色调变化本身就是叙事：
- 暖色调 → 突然切冷色调 = 情绪骤变、危险来临
- 低饱和 → 逐渐高饱和 = 希望、觉醒、从阴暗走向光明
- 正常色温 → 偏绿/偏黄 = 记忆/闪回/异世界

**提示词写法**：色调变化写进时间轴，如「[00:00-00:07] 暖黄色调……硬切至 [00:07-00:15] 色调骤然变为冷蓝灰」

### 与「稳定性技巧」的关系

- **默认求稳**：难镜头、长台词、手部特写 → 仍优先 **缓慢、连贯、单主运动**。  
- **要燃**：用 **短镜 + 拆条 + 环境连锁反应 + 声画陡升**，不要与「全程极速长跟拍 + 全身绝对清晰」同时硬要。

## 五维度诊断（写提示词之前的第一步）

> **外源交叉**：抖音「32 万观看 AI 视频教程」系列（交叉注意力权重分配）；VO3 [5-layer framework](https://www.vo3ai.com/blog/the-5-layer-prompt-framework-behind-cinematic-ai-video-and-how-to-use-any--2026-03-31)；[2048AI · 母提示词系统](https://2048ai.net/698d935054b52172bc5b49cd.html)。

### 核心理念：参考素材信息越满，提示词越做减法

AI 视频模型（Seedance 2.0）同时接收 **图像/视频参考**（视觉编码器）和 **文字提示词**（文本编码器），两者在模型内部争夺 **交叉注意力权重**。当参考素材已经包含丰富的视觉信息时，提示词里**再重复描述同样的内容**，等于强行让文本特征和图像特征互相打架，反而导致：

- **特征污染**：文字描述的细节覆盖了参考图的真实细节（如文字写的「暖黄光」污染了参考图里的冷光）
- **注意力分散**：模型把算力浪费在「猜哪个信息源为准」上，而不是全力把画面雕刻到极致

**极端案例**：拿一张信息量拉满的名画（主体、环境、光影、美学全在画里）做 `@首帧`，提示词只写一句运镜指令（「围绕中心轴环绕旋转后缓缓回拉」），效果远好于长篇重复描述画面内容——因为 100% 算力都用在了解算运镜轨迹上。

### 五维度扫描表

**每次写提示词前，先对照 `@素材` 扫一遍以下五个维度，判断哪些已被素材锁定、哪些是空白需要文字填充**：

| 维度 | 含义 | 什么时候素材已锁定（可省略文字） | 什么时候需要文字补写 |
|------|------|--------------------------------|---------------------|
| **① 绝对主体与物理动视** | 谁、穿什么、在做什么动作、身材体态 | `@人物参考图` 已锁五官/服装/体态时，**不重复写外貌** | 参考图只有静态姿势，动作/表情变化需要文字驱动 |
| **② 环境场与情绪光影** | 空间、天气、光源方向与色温、情绪氛围 | `@场景参考图` 或 `@首帧` 已包含完整环境时，**不重复写场景** | 无场景参考、或需要与参考图不同的光线/氛围时 |
| **③ 光学与摄影机调度** | 景别、运镜、焦段、角度、稳定器感 | **几乎永远需要文字写**——静态图/照片无法传达镜头运动 | 始终需要 |
| **④ 时间轴与状态演变** | 时间码内的动作/状态变化节拍 | 画面纯静场（如延时摄影、纯环绕展示）时可省 | 有动态变化、台词、分阶段动作时必须写 |
| **⑤ 美学介质与底层渲染** | 画风锚（写实/油画/3D/赛璐璐）、画质词、胶片感 | 参考图风格极明确（如一张油画做首帧）时，**少写或不写画风词**，避免文本和图像风格打架 | 无参考、或需要风格偏移（如把照片变成赛璐璐）时 |

### 诊断结果 → 提示词策略

| 素材信息量 | 提示词策略 | 典型场景 |
|-----------|-----------|---------|
| **素材锁定 4-5 个维度**（如精致底图做首帧） | **极致克制**：只写运镜 + 必要的动态变化，一个多余形容词都不加 | 名画/精美插画/高清实拍照 → 视频 |
| **素材锁定 2-3 个维度**（如人物参考图 + 场景图） | **定向补写**：只补空白维度（通常是运镜 + 动作 + 时间轴），已锁维度最多一句话呼应不展开 | 超写实口播（有角色三视图 + 场景图）|
| **素材锁定 0-1 个维度**（纯文生视频或只有粗略参考） | **全面展开**：七要素 / 八要素全写，按万能公式结构化 | 纯文字创意 → 视频 |

### 交付流程中的诊断步骤

当用户提供了 `@素材` 时，**先输出一段简短诊断**（在出提示词之前）：

> 「这组素材已锁定：① 主体外貌与服装（@图片1 三视图）、② 环境光线（@图片2 场景图）、⑤ 写实画风（参考图本身即真实摄影）。需要文字补写的维度：③ 运镜（固定机位 + 微微仰拍）、④ 时间轴与动作（台词节拍 + 表情变化）。提示词将省略外貌和场景的重复描写。」

用户确认后再出最终提示词。**若用户未提供素材查看**，则按现有七要素全面展开，不做减法。

## 默认风格基调

**与业务对齐（2026）**：用户侧视频以 **两大主档画风** 为主——**① 超写实电影风**、**② 3D 渲染系列**。其中 **②** 下 **并列两系**（任选其一，勿混用语义冲突词）：**②a 国漫/仙侠史诗系**、**②b 皮克斯系风格化 3D 卡通**（圆润造型、柔光、非照片级真实）。  
**2D动漫/卡通** 仍作为 **用户指定或题材明确需要扁平赛璐璐/日漫叙事** 时的备选，不作为默认首推。

> **画风模版按口令触发**：全部集中在 `jimeng-styles.mdc`——A 节 超写实实拍真人、B 节 2D 动漫/赛璐璐、C 节 搞笑彩绘极简、D 节 手绘铅笔速写。本文件只写 ①/②a/②b/③ 的总览方向，不重复模版细节。

### ① 超写实电影风（主档之一）

- **画面风格**：真人级或准真人级质感，电影摄影语言，自然肤色与材质（织物、皮肤、水面、金属反射可按题材取舍）。
- **核心优势（与 Seedance 契合点，多源共识）**：物理细节（风、水、布料）易做顺；**角色一致性与面部**在参考图锁身份时常被强调；慢速、连贯动作更稳。参见 [redreamality 指南](https://redreamality.com/cn/blog/seedance-2-guide/)、[YouMind 撰写指南](https://youmind.com/zh-CN/blog/seedance-2-0-prompt-guide-zh) 及海外「光影配方/电影结构」类总结（如 [Best Seedance Prompts · Lighting Recipes](https://www.bestseedanceprompts.com/blog/seedance-2-lighting-and-color-recipes)）。
- **适合题材**：情感故事、治愈风光、生活美学、数字人短剧、纪实感品牌片等。
- **流量逻辑**：视觉冲击强、停留与转发意愿高；需避免「假」则依赖 **具体光位与材质句** 而非空喊「电影感」。

### ② 3D 渲染系列（主档之一，二选一或分镜分条各用一种）

#### ②a 国漫/仙侠史诗系

- **画面风格**：**三维国漫渲染**（非扁平赛璐璐），中式美学（楼阁、山水、祥云、竹叶、甲胄、广袖），史诗场景与可选法术/剑气/灵力等 **可见特效**。
- **核心优势**：大全景建立感 + 仰拍/环绕 + 体积光与粒子，易出情绪峰值；「意境」须落成 **光色+轨迹+环境反馈**（见本文件「仙侠特例」「调性速查」）。多镜头中文示例见 [redreamality](https://redreamality.com/cn/blog/seedance-2-guide/)。
- **适合题材**：神话魔改、修仙、古法相斗、古装史诗、国风剧情短片。

#### ②b 皮克斯系风格化 3D

- **画面风格**：**三维卡通渲染**——圆润或适度夸张比例、干净材质与柔光全局光照，**不追求**真人皮肤与照片级写实；可参考皮克斯/梦工厂式 **表情细腻的喜剧或温情感**。
- **核心优势**：表情与肢体语言易夸张、适合 **合家欢、萌系、神话搞笑魔改、盲盒感角色**；与 **① 超写实** 区分：**①** 要电影级真实，**②b** 要 **可爱/滑稽/温暖的风格化**。
- **适合题材**：亲子向、萌系科普、搞笑神话改编、需要「可爱反派/夸张反应」的剧情。
- **流量逻辑**：亲和度高、分享门槛低；提示词要写清 **圆钝轮廓、柔光、饱和度适中防塑料感**。

**②a 与 ②b 同场使用**：若单条视频统一画风，**择一锚死**；若用户明确要求「前面国风后面萌系转场」，拆 **两条生成** 再接，避免单条里风格词内战。

### ③ 2D动漫/卡通（备选）

- 画面风格：2D动漫/卡通插画，清晰描边、平涂或赛璐璐，阴影层次简洁。
- 适用：搞笑条漫感、日漫叙事、明确要 **扁平化** 或 **低成本魔改喜剧** 时由用户选定。
- 与 **①**、**②a/②b** 不得混用语义：同一条提示词不要既写「真实摄影毛孔」又写「赛璐璐描边」；不要既写「仙侠剑气」又写「泡泡玛特盲盒头身比」除非用户要刻意混搭梗。

### Seedance 2.0 · 主画风关键词方法论（2025–2026 多源交叉，交付句用纯中文）

以下与全文 **万能公式**、**电影级画面归纳**、**一镜一主运动**、**简易道具不出图** 及 **产出语言默认纯中文** 同时使用。镜头切换写 **「切换至」**；运镜写 **缓慢推镜、拉远、环绕、跟拍** 等中文。

#### A. 超写实电影风怎么写才落地

| 层次 | 写什么 | 说明 |
|------|--------|------|
| **主体** | 年龄感、妆发、服装材质与颜色 | 与 `@人物参考` 一致时写「保持与参考图同一人物」 |
| **场景分层** | 前景/中景/远景各一项具体物 | 替代「很好看的工作室」类空话 |
| **光与色** | **具体光型+方向+色温** | 如：侧逆光轮廓光、窗光软散射、黄昏暖金主光冷蓝阴影、霓虹主光青蓝辅光；可叠 **低调/高对比/柔肤** 等可拍词汇 |
| **镜头** | 景别 + **一种主运镜** + 可选浅景深 | 慢推、手持微晃、跟拍一员；避免同句三个机位 |
| **动作** | **缓慢、连贯、自然** 优先 | 进阶情绪戏再加快；忌与「全程清晰+极限运动」矛盾 |

## 工作流程

### 第零步：交付前强制复习（每次出视频关键词前必执行）

**每次为用户产出视频关键词之前**，必须先重新阅读本文件以下章节，确保把已收集的方法论用到位：

1. **景别叙事逻辑速查** — 每个镜头的景别选择是否有明确叙事目的？是否按"远景建立→中景引入→近景情绪→特写转折→远景收束"的信息分发逻辑拆分？
2. **镜头角度=情绪本身** — 仰拍/俯拍/侧面/背面/倾斜/贴地各传递什么情绪？是否为了叙事选择了最有表现力的角度而非默认平视？
3. **光线方向→情绪语义反查表 + 色彩叙事** — 光位和色调是否服务于当前场景的情绪？
4. **构图法则** — 是否利用了框中框、引导线、前景遮挡、对称/不对称等构图？
5. **对话镜头升级路径** — 对话场景是否从双人中景升级到过肩反打？是否遵守180°和30°法则？
6. **人物出场模式** — 角色出场用了英雄感/悬念感/故事感中的哪种？是否用了对应的镜头语言？
7. **剪辑转场** — 镜头之间的衔接是否有叙事意图（硬切紧张、匹配剪辑流畅、声画预叙）？
8. **反应镜头法则 + 喜剧节奏** — 反应镜头时长是否大于事件本身？笑点前是否留了节拍停顿？
9. **难角度辅助** — 每个非平视角度是否补写了该角度下的可见元素？

**自检后再出关键词**。如果发现某个镜头只是"平视中景固定拍"却能用更有表现力的角度，必须主动升级。

### 提问顺序（严格按此顺序，一次性用AskQuestion提问）

用户给出大致剧情后，用一次 AskQuestion 按以下固定顺序提问，所有题 allow_multiple: true，每题最多5个选项：

**Q1. 这段剧情想表达的感觉**（根据剧情内容定制选项）
- 例如：搞笑轻松 / 温馨感动 / 紧张刺激 / 热血燃 / 伤感治愈

**Q2. 镜头数量**（每个选项后面简要标注镜头设计思路）
- 1个镜头 — 一个完整动作一气呵成
- 2个镜头 — 前半段铺垫+后半段高潮或反转
- 3个镜头 — 起势+发展+收束 节奏最完整

**Q3. 台词（填空题形式）**（必问不可省略）
- 无台词
- 有台词（请在聊天中告诉我谁说什么）

**Q4. 整体风格**（默认优先 **①超写实电影风**、**②a国漫仙侠3D**、**②b皮克斯系3D** 的细分；备选 **③2D动漫**）
- 根据剧情推荐最适合的3-5个风格选项（每条带一句画面定位，避免只写风格名）

**Q5-Q7. 画面细节**（根据需要选问，不必全问）
- 场景环境细节
- 色调/光影/氛围
- 其他需要确认的维度

用户选"有台词"后，必须在聊天中追问具体台词内容，拿到台词后再产出关键词。

### 第二步：确定锚点

用户选择确认后，先内部确定以下锚点，所有prompt统一使用：

- **风格锚**：统一的风格描述
- **色调锚**：统一的色调描述
- **光源锚**：统一的光源方向和类型
- **环境色**：场景对角色和元素的颜色影响

锚点一旦确定，在同一个脚本/故事的所有画面中保持不变（除非用户明确要求切换场景氛围）。

### 第三步：产出关键词

按统一流程产出**当前这一段剧情**的关键词：

1. **主体设定图生图关键词（单张 16:9 三视图总览）** — **仅一张** **16:9 横版**，中性背景（白底/灰底），**一张图内**含：全身正视、侧视、后视三视图 **以及** 面部特写区（至少正面大特写，眉眼鼻嘴清晰）；版式钉死 **左约 1/3 特写 + 右约 2/3 三视图**（见下文「三视图生图模板」）。**不默认**再拆多张、不默认其它比例（见 **`jimeng-core-delivery.mdc`** 三视图默认章）。若该角色已生成过同一套设定图，则跳过，直接复用
2. **场景图生图关键词** — **仅当用户当次明确要求**「出场景图 / 生成某某场景参考」等时才产出（见 **`jimeng-core-delivery.mdc`** 道具/场景默认不出图章）。未要求前用视频 prompt 文字描述环境，或用户自备场景图后 `@` 引用。若场景与前一段相同则跳过
3. **辅助设计元素生图关键词** — **仅当用户当次明确要求**「给道具出图 / 生成道具参考」等时才产出（见 **`jimeng-core-delivery.mdc`** 道具/场景默认不出图章）。**不因**「复杂道具」或「系列复用」**自动**单独出图；未要求前一律在视频 prompt 里用文字描述材质与外形（见下文「简易道具 vs 复杂道具」）
4. **视频生成关键词** — 角色与场景须与 **参考图 + `@`** 绑定；道具 **默认** 只在句内文字描述；**仅当用户明确要求** 出道具图后才在视频中用 `@道具图`；写入环境色和防崩约束。  
  - **本仓库默认（Seedance 2.0）**：**全能参考生视频** — 须交付 **「素材→@序号」映射**（如 `## 4.5` / `## 7`），且 **分镜提示词正文内写 `@图片N` / `@视频N`**，与即梦内上传顺序一致。**禁止**默认只给零参考纯文长段（见 **`jimeng-core-delivery.mdc`** 全能参考章）。  
  - **仅当用户当次明确**「只要纯文、不要参考与 @」时：可改用括号素材名（如「参考某某设定图」）而不写序号。  
  - **对外部/历史模版**若仍用「仅素材名」表述，转到本仓库项目时须 **改为含 `@` 的全能参考交付**。

**交付形式（强制）**：除写入项目文件外，**须在当次对话中输出可直接复制的完整提示词正文**——按「角色设定图 → 场景图 → 分镜视频」分块，每块用独立代码围栏，便于用户粘贴即梦/Seedream/Seedance；**禁止**仅给出文件路径而不给可复制正文。用户若声明「以后都要这样」，默认始终遵守本条。

**修订再交付**：凡对关键词 **增删、改版、纠错**（含角色性别锚定、画幅、负向词等），保存文件后 **须在当次对话再发一遍全文可复制块**（或至少发变更段落+说明「其余同前」），不得只写「已更新文件」而不给可粘贴正文。

### 第四步：询问下一段剧情（循环推进）

同一个脚本的故事是连贯的，一段剧情的关键词产出后，必须主动询问用户下一段剧情内容，形成"产出→追问→产出"的循环，直到整个故事结束。

#### 循环规则

1. **每完成一段剧情的关键词产出后**，立即询问用户："这段画面的关键词已产出，接下来的剧情是什么？"（用自然语言询问，不用 AskQuestion 工具）
2. **用户给出下一段剧情后**，回到第三步产出关键词，不需要重新走第一步的提问流程（风格、模式等已在第一段确定）
3. **如果新剧情涉及场景/氛围重大变化**（如从室内转到室外、从白天变成夜晚），需要在产出关键词前简要说明锚点中哪些会调整（如色调锚从"暖黄室内灯光"变为"冷蓝月光"），并确认用户同意
4. **用户明确表示故事结束或没有更多剧情时**，结束循环

#### 跨画面连续性要点

在产出后续画面的关键词时，必须注意与前面画面的连贯性：

- **角色复用**：同一角色在不同画面中使用相同的三视图参考，不重新生成。角色的核心外观描述词保持一致
- **锚点继承**：风格锚、色调锚在整个故事中保持统一，除非剧情需要转换（如回忆段落、时间跳跃）
- **情绪递进**：后续画面的氛围描述要承接前一段的情绪走向，而非割裂跳跃
- **动作衔接**：如果前一段的结尾动作和下一段的开头动作相连，需要在下一段的开头镜头中体现承接关系（如前一段角色挥拳结束，下一段从拳头收回的姿态开始）

# 一、角色设计原则（生图前必读）

在写任何角色生图prompt之前，先按以下原则完成角色的设计思考，再转化为提示词。

## 剪影与形体语言

角色即使涂成纯黑剪影也必须能被辨认出来。通过基础几何形体传达性格：
- **三角形/尖锐线条** → 攻击性、危险、敏捷（适合战士、反派）
- **圆形/曲线** → 亲和、天真、柔软（适合萌系、治愈系）
- **方形/粗壮线条** → 稳重、力量、可靠（适合守护者、壮汉）

在prompt中体现：描述角色的体型轮廓、标志性外形特征（如飘动的披风、夸张的肩甲、标志性武器），而不是堆砌装备清单。

## 三色配色法则

为角色建立主色（60%）、辅色（30%）、点缀色（10%）的配色方案：
- **主色**定基调（占面积最大的颜色，如铠甲/服装主体色）
- **辅色**做层次（内衬、护具、次要装饰的颜色）
- **点缀色**做亮点（宝石、眼睛、发光纹路等小面积高饱和色）

在prompt中体现：明确写出"主色XX，辅色XX，点缀色XX"，避免写成一堆颜色的罗列。

## 服装设计原则

1. **少而精**：1-2个核心设计元素贯穿全身即可，不要每个部位都堆不同的装饰
2. **材质讲故事**：材质要体现角色身份和经历——将军的铠甲该有战损，书生的衣袍该是素净的棉麻
3. **适配世界观**：服装必须属于角色所在的世界，而非随意混搭不同文化
4. **功能合理性**：战士的铠甲要看起来能活动，仙人的衣袍要看起来能飘逸
5. **头身比决定风格档位**：写实成人7-8头身，少年英气6-7头身，Q版2-3头身——一旦确定就不能和场景的写实度冲突

## 标志性记忆点

每个角色需要1-2个一眼能记住的视觉符号，在prompt中重点描写：
- 可以是独特的配饰（红色发带、特殊纹身）
- 可以是体态特征（伤疤、异色瞳）
- 可以是标志性道具（金箍棒、特殊武器）

## 超写实人物：面部与身材差异化（Seedream 5.0 / Seedance 2.0）

> 多角色同批出图时，若只写「年轻男性」「古铜色皮肤」，模型易收敛成**同一张脸**。须把「美」拆成**可画维度**，且**角色之间至少三处互斥**（脸型、眼型、眉形、鼻型、唇形、发型、肩颈比例、肌肉量等）。

### 面部（每项尽量只写可观察特征，避免抽象形容词）

| 维度 | 可写内容（择要组合，勿全空） |
|------|------------------------------|
| **脸型与轮廓** | 方下颌/尖下颌/椭圆脸；下颌线锐利或柔和；颧骨高或平；太阳穴是否凹陷 |
| **眉与眼** | 眉形（剑眉/细弯眉/一字眉）；眼型（深眼窝杏眼/细长眼/圆眼）；双眼皮或单眼皮；虹膜颜色（琥珀/深褐/灰蓝） |
| **鼻** | 鼻梁直挺或微弯；鼻头圆钝或尖窄；鼻翼宽窄 |
| **唇与表情** | 薄唇/唇线分明或略厚；嘴角下垂或上扬；静态表情（冷峻/心虚） |
| **须发与肤** | 发际线高低；卷发紧或松；胡须有无；肤色冷调或暖调； optional 浅色疤痕位置 |

### 身材与体态（与脸配套，避免双角色共用「匀称」）

| 维度 | 可写内容 |
|------|----------|
| **肩颈** | 斜方肌明显宽肩 vs 窄肩溜肩；颈粗短 vs 颈长纤细 |
| **躯干** | 胸背厚实倒三角 vs 单薄扁平；腰线明显与否 |
| **四肢** | 前臂粗壮血管微显 vs 手腕细；大腿肌肉线条 vs 修长无肌肉感 |
| **头身比** | 英雄感略矮壮 vs 文弱偏高瘦（用视觉词而非数字也可） |

### 多角色清单（交付前自检）

- **互斥**：A 与 B 至少 **3 条**不重叠特征（例：A 方下颌宽肩厚胸；B 尖下颌窄肩清瘦）。  
- **禁止**：多人共用同一组「剑眉深目高鼻梁」而无差别。  
- **参考**：单张设定图仍用 **左1/3特写+右2/3三视图**；特写区须能读出上表至少 **脸3项+发型1项**。  
- **视频**：Seedance 侧在主体句重复 **脸型+眉/眼+肩背关键词**（与 `@设定图` 对齐），一致性优于只写「同一人物」。

### 神话/历史角色的性别与样貌锚定

- 神话人物**无真实照片**，应以 **文本身份 + 考古与艺术史图像** 为锚（如古希腊陶瓶画中 **帕里斯/亚历山德罗斯** 多为 **持弓的青年男性**，着 **东方化华丽男装**，与阿喀琉斯对照时偏文弱但仍为 **男性身体结构**）。  
- 提示词须显式写：**成年男性或青年男性、王子/战士身份、典型道具（弓）**；避免「美貌」「俊美」单独成句导致模型判成女性。  
- 易误判性别时：在正文与负向中双写 **男性骨相（喉结、窄骨盆、男式肩线、男性手足）**；负向排除 **女相、女装、丰胸、网红锥子脸** 等。  
- 交付时在项目文件或对话中可附 **两行依据说明**（文献/图像类型），便于用户复核，非强制长文考据。

## 色调与高级感

避免使用过于刺眼的高饱和纯色"塑料感"配色。根据风格档位选择合适的配色策略：
- **2D动漫/卡通风格**：可以使用相对鲜明的色彩，但需要统一色调——推荐使用同一色温下的和谐色板，避免冷暖色无逻辑混搭。参考吉卜力、新海诚等作品：色彩鲜明但不刺眼，有空气感和光影层次
- **3D动画风格**：色彩饱满明快但不刺眼，用柔和的全局光照让颜色自然过渡。参考皮克斯/迪士尼3D的配色：主色高饱和、环境色柔和、整体画面有"糖果感"但不廉价
- **写实/CG风格**：使用浊色调营造厚重感（深棕、暗金、烟灰、墨黑、朱红、檀绿）

# 二、场景设计原则（生图前必读）

在写任何场景生图prompt之前，先按以下原则完成场景的设计思考，再转化为提示词。

## 场景服务叙事

场景不是被动的背景板，而是"无声的叙事者"。设计场景前先问：
- 这个场景要传递什么情绪？（压迫、温馨、荒凉、神圣）
- 这个场景发生了什么故事？（战后废墟要有破坏痕迹，生活空间要有使用痕迹）
- 角色在这个场景中是什么状态？（场景气氛要衬托角色情绪，而非割裂）

在prompt中体现：不要只写"一座宫殿"，要写出宫殿的状态和故事感（"经历过战斗的宫殿，柱体有裂纹，地面散落碎片"）。

## 前中后景分层

用三层结构建立画面纵深感，避免"贴纸般"的平面画面：
- **前景**（画面最近处）：放置局部元素制造遮挡关系，如岩石、树枝、飘落的花瓣、碎片，增强立体感和代入感
- **中景**（画面核心区）：角色活动的主要空间，需要最清晰的细节
- **背景**（画面最远处）：交代环境全貌，用虚化、低饱和、偏冷色调拉开距离

在prompt中体现：明确写出"前景XX，中景XX，背景/远处XX"的分层描述。

## 场景配色与氛围

场景同样遵循60-30-10配色法则，且必须与角色配色协调：
- **角色主色与场景主色应形成对比**：角色暗金色 → 场景可用深灰蓝或暗石白作为衬托，让角色不被背景"吞掉"
- **冷暖推进拉深度**：前景偏暖 → 中景自然色 → 远景偏冷，制造空间纵深
- **大气透视**：远景的饱和度降低、明度偏高、略带蓝灰色调，模拟真实空间感

## 光影讲故事

光影不只是照明，更是情绪工具：
- **主光源**：决定光照方向和画面基调（金色夕阳 = 史诗感，冷蓝月光 = 孤寂感）
- **轮廓光/逆光**：勾勒主体边缘，将角色从背景中"剥离"出来
- **环境光**：填充暗部细节，避免死黑区域
- **体积光/丁达尔效应**：光线穿过烟尘/雾气形成可见光束，增强画面氛围

在prompt中体现：
- **2D动漫/卡通风格**：用简洁的光影分区（亮面/阴影面）和色温变化表达光照，如"温暖的夕阳将画面染成橘黄色调，角色身上投下清晰的斜长阴影"。不需要描写复杂的物理光学效果
- **3D动画风格**：用柔和的全局光照描述，如"柔和的顶光照亮角色，背光处有微弱的环境反射光"。光影过渡比2D更柔滑，但不需要写实的焦散、次表面散射等物理描述
- **写实风格**：明确写出光源方向、类型和物理光学效果

## 场景细节的"少而准"

避免堆砌无关细节，只放有叙事功能的元素：
- 战场 → 裂开的地面、断裂的武器、飘散的旗帜碎片（讲述战斗的故事）
- 书房 → 摊开的书卷、冒着热气的茶杯、烛台蜡泪（讲述主人的生活）
- 废墟 → 青苔覆盖的石柱、倒塌的屋梁、从裂缝中生长的藤蔓（讲述时间的故事）

不要在一个场景里同时出现十种不同的细节元素，3-5个叙事性细节足矣。

## 建筑/空间的尺度感

通过参照物让观众感知空间的真实大小：
- 在巨型建筑旁放置人类尺度的物件（台阶、门扉、栏杆）作为比例参照
- 用远处的渺小建筑群衬托近处建筑的宏大
- 用雾气/云层的遮挡暗示建筑延伸到视线之外

# 三、元素设计原则（生图前必读）

辅助设计元素（道具、装饰、粒子特效等）必须和角色、场景属于同一个世界。

## 写实度系数统一

所有元素必须维持相同的写实度档位：
- **2D动漫/卡通风格**：道具用简洁的色块和清晰描边表现，细节用线条而非材质纹理，造型可适度夸张变形
- **3D动画风格**：道具用圆润饱满的3D造型，表面干净有光泽但不追求照片级真实，可适当风格化夸张
- **写实/CG风格**：道具用写实质感（金属有反射、木头有纹理、布料有褶皱）
- 绝不允许跨档位混搭（如3D角色配2D平涂道具，或卡通角色配写实场景）

## 元素的形体语言要跟角色一致

元素的造型风格应呼应角色的形体语言：
- 三角形/尖锐体态的战士 → 武器也该有尖锐棱角、锋利线条
- 圆润可爱的角色 → 道具也该圆滑柔和
- 方正稳重的角色 → 工具也该厚实敦重

## 材质和做旧程度统一

材质的细节程度和新旧感要和角色与场景匹配：
- **2D动漫/卡通风格**：不用描写写实材质细节，改用颜色明暗、线条粗细、色块形状来暗示材质差异和新旧感。如"颜色略微黯淡的旧斗篷"而非"布料纤维磨损起毛"
- **3D动画风格**：用表面光泽度和颜色饱和度暗示新旧，如"光泽略微黯淡的旧铠甲"而非"表面布满微观划痕和锈蚀"。3D动画的旧物是"颜色变暗"而非"材质破损"
- **写实风格**：可以描写具体的材质细节——战损、磨损、包浆、纤维磨毛等

## 配色从属于整体

元素配色必须从属于已确定的整体配色方案：
- 使用角色的主色、辅色、点缀色中的颜色
- 可以在明度和饱和度上微调，但不引入全新的色相
- 发光/特效色可以是唯一例外（如金色光芒、蓝色魔法），但也要和整体色调和谐

## 叙事功能优先

每个辅助元素都应该有存在的理由：
- 它能体现角色的身份或背景吗？（战士的佩刀 vs 学者的书卷）
- 它能推动画面的叙事吗？（地上的断剑暗示战败）
- 它能增强画面的氛围吗？（飘散的火星增强紧张感）

如果一个元素不满足以上任何一条，就不需要生成它。

# 四、生图提示词规则（Seedream 5.0）

## 生图公式

### Seedream 5.0 五要素结构

Seedream 5.0 对自然语言的理解大幅增强，提示词应以**连贯的描述性语句**为主体，配合短词语的美学修饰。不要堆砌无关形容词，要描述你实际想要看到的具体画面。

```
主题（画什么）+ 动作/姿态（在做什么）+ 环境/场景（在哪里）+ 风格/美感（什么风格）+ 技术细节（光线、视角、比例、文字等）
```

### 基础公式（快速出图）

```
主体（外观细节）+ 风格 + 美学修饰
```

用连贯自然语言描述画面内容（主体+行为+环境），用短词语描述美学（风格、色彩、光影、构图）。

### 完整公式（精细控制）

```
主体描述 + 动作/姿态 + 场景/环境 + 风格化 + 光影 + 视角/景别 + 色调/氛围 + 材质 + 尺寸比例
```

### 图生图公式（Seedream 5.0 精准编辑）

图生图提示词必须包含三个层次，明确告诉模型什么保留、什么改变、什么禁止：

```
保持不变的部分（如「保持主体身份和构图不变」）+ 应该改变的部分（如「将背景改为极简白色」）+ 必须避免的内容（如「不要添加额外文字与无关物体」）
```

## 三视图生图模板

用于生成角色设定参考图，确保后续视频中角色一致性。

### 默认交付（强制）

- **本项目用户约定**：角色 **只要** **单张 16:9 三视图总览图**（一张看清脸 + 三视）；**禁止**默认拆成多张角色图或改用 9:16 / 1:1 等替代（见 **`jimeng-core-delivery.mdc`** 三视图默认章）。
- **必须输出在一张图内**：不要拆成多张全身图另存；即梦侧用 **单张角色设定图** 统一锁脸、锁服装。
- **画幅**：角色设定图 **固定 16:9 横屏** 作为默认与首选；场景图、参考生视频 **默认 16:9**（与成片比例一致时再指定其他比例）。
- **固定排版（防乱跑版）**：必须用提示词 **钉死分区**，禁止「随意分格/随机排版」。推荐 **唯一默认版式**：
  - **整图 16:9 横构图**；
  - **左侧约三分之一画面宽度**为 **面部特写区**（正面大特写，眉眼鼻嘴清晰，占满该左栏高度）；
  - **右侧约三分之二画面宽度**均分为三列并排，依次为 **全身正视图、全身侧视图、全身后视图**，人物站姿一致、同一套服装；
  - 分区线清晰、对齐网格感、无元素跨区漂移、无面部特写跑到右侧或角落。
- 若项目另有版式，须在提示词中写明「左/右/上/下各占画面百分之多少」，仍要求 **单图内** 三视图 + 特写。
- **超写实真人** 例外版式（三等分并排，无面部特写区）见 **`jimeng-styles.mdc` → A 节**。

### 必选脚手架（Seedream 角色设定 · 每条必写）

以下句子为 **防特写与三视图不一致** 的技术约束，**不改变**人物美丑与服装款式本身，**每条用户交付的角色设定提示词须连续包含**，**不得**有时省略有时不写：

- `横版16比9画幅，单张角色设定图，严格分区禁止随机排版，`
- **`同一角色同一套服装，特写区与全身三视图区须完全一致，同一发型同一服饰，禁止左右分区人物不一致，`**

再接分区描写、主体与风格句。**多造型探索**时须 **方案 A / 方案 B 各写一条完整全文**，**禁止**在同一条里用 **「或」「之一」「可」「任选」** 让模型抽卡（强锁定禁「或」见下节）。

### 公式（单图：左1/3特写 + 右2/3三视图，16:9）

```
横版16比9画幅，单张角色设定图，严格分区禁止随机排版，同一角色同一套服装，特写区与全身三视图区须完全一致，同一发型同一服饰，禁止左右分区人物不一致，
画面左侧约三分之一宽度为面部特写区，正面面部大特写占满左栏高度，眉眼鼻嘴清晰，表情中性，
画面右侧约三分之二宽度内三等分三列，全身三视图人物IP设计，从左到右依次为正视图、侧视图、后视图，
[主体名]正视图，[主体名]侧视图,[主体名]后视图，
分区边界竖直清晰，对齐整齐，不重叠不穿模，
[主体描述]，[风格关键词]，[外观细节]，背景白底，无环境色，高清，人体结构正确，五官对称
```

若当次需要 **指定单一表情**，在同条内写死为 **「表情为……」**，**不**与「表情中性」并列用选择关系。

### Seedream 角色设定：强锁定禁「或」

- **同一提示词内** 不用 **「或」「之一」「可」「任选」「双马尾或短发」** 等让模型二选一；发型、眼镜有无、服装款式 **各条只定一种**。  
- **背景底色**：每条只写 **一种**。**背景白底** 与 **背景浅米色素描纸纹** 若需对比，须 **各写一条完整全文**，禁止单条内并列两种底色。  
- 助手交付方案 C 系 **多方案** 时：**方案 A、方案 B、方案 C 各一条完整可复制全文**，**不**在单条内合并。

### 示例

```
横版16比9画幅，单张角色设定图，严格分区禁止随机排版，同一角色同一套服装，特写区与全身三视图区须完全一致，同一发型同一服饰，禁止左右分区人物不一致，
画面左侧三分之一宽度为面部特写区，正面大特写，微笑，五官清晰，
画面右侧三分之二宽度三等分列，全身正视图侧视图后视图从左到右排列，
女孩正视图，女孩侧视图，女孩后视图，
一个穿绿色汉服的可爱女孩，卷发，精致发夹，穿汉服裙子，
泡泡玛特，迪士尼，皮克斯，盲盒玩具风格，背景白底，高清摄影
```

### 旧版公式（仅全身、无特写时备用；不推荐默认使用）

```
全身，[主体描述]，三视图人物IP设计，正视图，侧视图，后视图，
[主体名]正视图，[主体名]侧视图，[主体名]后视图，
[风格关键词]，[外观细节]，白底，高清
```

### 三视图关键要点

- **默认**：单图含三视图 + 面部特写；**版式默认左三分之一面部特写、右三分之二三视图并列**，横版 **16:9**；交付给用户的 Seedream 提示词须写清「严格分区禁止随机排版」避免即梦乱放。
- **必选脚手架**：**「同一角色同一套服装」** 与 **「特写区与全身三视图区须完全一致…」** 见上文 **「必选脚手架」**；**每条角色设定须写**，不得有时省略。
- 必须写"三视图"+"正视图，侧视图，后视图"双重强调；并写明 **左1/3 / 右2/3** 与 **16:9**，避免模型只出全身无脸或特写错位。
- 将"[主体名]正视图，[主体名]侧视图，[主体名]后视图"中的主体名替换为实际角色
- 背景底色每条写死一种；**白底** 与 **浅米纸纹底** 对比试验须 **两条全文**，见 **「Seedream 角色设定：强锁定禁或」**。
- "全身"确保三视图区角色完整展示；特写区与全身区须同一角色、同一发型与服饰
- 风格词（泡泡玛特/迪士尼/皮克斯/CG动漫/写实摄影等）决定角色整体调性，**全文风格一致**

### Q版丑萌 IP：外形差异化与「方案 C」系列优化（外源共识 · 检索摘要·2025–2026）

> **用途**：多角色共用 **同一滑稽丑萌彩铅系**（用户侧常称 **方案 C**）时，助手须在 **不推翻用户已肯定的画风与版式** 的前提下，轮换 **外形变量**，避免每个角色都落成「海胆头+圆点眼+粗框眼镜+倔强嘴」同一套路。**除非用户明确否定**，下列 **已锁定项** 在协作中 **持续沿用**；**可变项** 按角色表逐格填，一点一点迭代。

#### 与用户项目对齐的「锁定项」（默认持续，除非用户否定）

| 锁定 | 说明 |

## 场景图生图模板

用于生成视频背景/环境参考图。

### 公式

```
[场景描述]，[时间/天气/光线]，[风格化]，[色调/氛围]，[画面净化指令]，[场景防崩约束]，[画质关键词]
```

### 画面净化规则

场景图和辅助元素图默认是纯环境/纯物件素材，必须主动排除干扰：
- **不需要人物时**：prompt末尾加上"无人物，无人影，空旷场景"
- **不需要文字时**：prompt末尾加上"无文字，无标识，无水印"
- **需要人物点缀时**：明确写出人物的数量、位置、大小和动作（如"远处一个模糊的小人影走在路上"），而非让AI随机生成
- **需要文字时**：用引号明确标注文字内容和位置（如"画面中央写着'大闹天宫'四个字"），而非让AI自由添加
- 辅助元素图同理：单独的道具/物件图必须加"无人物，无文字，纯[背景色]背景"

### 场景图防崩约束（必加后缀）

场景图末尾必须附加以下约束词，防止建筑/环境结构崩坏：

```
结构完整 透视正确 建筑比例合理 线条笔直无弯曲变形 无断裂结构 无漂浮物体 无重叠穿模 画面干净 无畸变 无模糊 高清
```

### 示例

```
中国古代庭院，凉亭中摆放着石桌、书籍和茶具，
阳光透过竹林洒下斑驳光影，清晨薄雾，
CG动漫风格，暖色调，宁静氛围，
无人物，无人影，空旷场景，无文字，无水印，
结构完整，透视正确，建筑比例合理，线条笔直无弯曲变形，无断裂结构，无漂浮物体，画面干净，无畸变，高清，16:9
```

## 辅助设计元素生图模板

用于生成视频中需要的道具、装饰物、信息图表、标题卡、图标、特殊物件等有设计感的实体素材。这些元素不是主角也不是背景，而是增强画面表现力的视觉点缀。

### 简易道具 vs 复杂道具（是否单独出参考图）

| 类型 | 示例 | 是否单独生成道具参考图 |
|------|------|------------------------|
| **简易道具** | 普通箭矢、单刀、长矛、书本、茶杯、石块、简易盾牌 | **否**。在视频prompt中写清材质与颜色（如「深木色箭杆金色箭羽三角金属箭头」）即可，与@场景图@三视图一并约束风格 |
| **复杂道具** | 花纹繁复的神器、标志性定制武器、需多镜头严格同形的机械/法器、带固定UI的全息界面 | **默认仍不出单独道具图**（除非用户明确要求出图）；视频中用文字描述；用户要求出图后再单独出辅助元素并用（参考@xxx） |

**原则**：多一张参考图就多一次合成对齐成本。**本项目**：**道具与场景图单独出 Seedream 均须用户明确要求**（见 **`jimeng-core-delivery.mdc`** 道具/场景默认不出图章）。**默认**少出场景/道具图，环境用视频 prompt 写清或自备图 + `@`；不因「复杂」自动出图。

### 公式

```
[物件名称及外观描述]，[材质/质感]，[风格化]，[视角]，[背景处理]，[画质关键词]
```

### 常见类型与示例

**道具/物件**：画面中角色使用或交互的实体物品

```

木质纹理桌面上，旁边散落几支毛笔和砚台，

```

**信息图/概念可视化**：将抽象概念转化为有设计感的视觉元素

```

牌匾边缘有精致雕花，背景是虚化的水墨山水，
```

**装饰/氛围元素**：漂浮粒子、光效、花瓣等用于叠加的素材

- 需要抠图叠加的元素用"纯黑背景"或"白底"方便后期处理

## 生图质量提升技巧

- **负向提示词**：在即梦高级设置的"负向提示词"输入框中填入：`低质量 模糊 变形 畸形 多余手指 缺少手指 粘连手指 多余肢体 断裂肢体 面部扭曲 五官不对称 比例失调 水印`
- **批量生成**：每次生成4张，从中筛选最优
- **引号标注文字**：需要画面中出现的文字内容用""包裹，Seedream 5.0的中文渲染能力有提升但复杂排版仍建议后期叠加
- **指定用途**：写明"手机壁纸""电商主图""PPT封面""视频封面"等提升适配度
- **专业术语用原文**：如 `Macro lens shot`、`Bokeh` 等英文术语效果更准确
- **人物防崩正向强化**：提示词中加入"人体结构正确 关节自然弯曲 五官对称 面部比例真实 手指五根数量正确 手部结构清晰 四肢完整"
- **姿势简化原则**：让角色手持物品比空手更稳定；避免十指交叉、比心等精细手势；避免肢体重叠交叉
- **局部迭代修复**：使用 Seedream 5.0 的笔刷局部重绘功能修复崩坏区域（如手指），无需全部重新生成
- **分辨率选择**：默认2K分辨率即可满足大多数需求，开启"超清"选项可进一步增强
- **单变量迭代**：对结果不满意时，每次只改一个参数（如只调风格 or 只调光影），便于定位问题
- **具体优于修饰**：Seedream 5.0理解能力更强，写"晨雾笼罩的松树林"比堆砌"美丽的、壮观的、令人惊叹的森林"效果好得多

## 检索摘要·写实生图去AI味（2026，多源交叉 + 用户实测降噪法）

> 适用：超写实/实拍感生图（锚点帧、场景、POV 素材）。核心：写「摄影简报」不堆关键词。

1. **顺序**：场景 → 光线 → 主体 → 镜头 → 材质 → 限制；写成句子，不写词块。
2. **空泛词是 AI 味来源**：「8K / 超写实 / 超高清 / 大师级」堆砌反而假；用具体相机语言替代（35毫米镜头 f/2.8 平视、柯达胶片色感、轻微胶片颗粒、低对比）。
3. **光感=光有方向**：必须写光从哪来、什么性质、影子落哪（如「冷白天光从左侧低角度穿过薄雾，刀刃一条窄高光，手背有受光面与阴影面」）；不写光线=默认平光=最假。
4. **细节做减法**：杂乱是 AI 味主因；背景元素砍到 1-2 个，**雾/景深是天然降噪器**，远景细节交给雾吃掉；地面留白用水洼反光撑质感。
5. **克制的不完美**：1-2 个人性化细节（旧疤、刀刃细划痕、磨毛缠布）即可，满屏做旧=杂乱。
6. **降噪固定尾段（用户抖音实测）**：`画面干净通透，材质完整自然，纹理平滑统一，主体清晰，背景层次分明，避免过度锐化、色斑、噪点、碎纹、崩坏和畸变`。
7. **负面精简定向**：只写「塑料质感、过度磨皮、假反光、无来源光线」等针对性条目，不堆长串。
8. **单点迭代**：一次只改一个变量，先固定光线+镜头，再调主体/构图。
9. **持刀类动作解剖锁定**：双手握刀写死「右手指节贴护手、左手小指包柄尾、两手间一拳缠绳空隙、两手不相贴、拇指内扣手背朝上」，否则必出双手攥护手/柄尾空长截的崩坏。

## 角色一致性工作流

1. 先用「单图三视图+面部特写」模板生成 **一张** 角色设定图
2. 再用"参考图"功能，将该单张设定图作为参考导入（近景与全身可同图裁切或整图引用，以即梦当前功能为准）
3. 在不同场景prompt中重复角色的核心外观描述词
4. 保持风格词统一（每张图都用同一个风格词）

## 合成协调性原则（最重要）

角色、场景、辅助元素是分开生成后合成为视频的，所以每条prompt必须在写的时候就考虑"合在一起是否协调"。这是所有规则中优先级最高的原则。

### 1. 环境色渗透（核心）

角色和元素必须在prompt中写明受到场景环境色的影响，否则合成后角色会像"贴纸贴在背景上"：

- **确定场景的主导光色**（如：金色夕阳、蓝色月光、暖黄室内灯、绿色森林漫射光）
- **角色prompt中必须写入环境光对角色的影响**：如"夕阳的暖橙色光照映在角色脸部和衣服上，阴影处带有淡淡的蓝紫色调"
- **辅助元素prompt中同样写入环境光影响**：如"金箍棒表面反射着周围环境的暖橙色光"
- **不同时段的环境色参考**：
  - 白天：白色主光，蓝色环境光，深蓝阴影
  - 清晨：淡黄/淡橙主光，柔蓝环境光
  - 傍晚/黄昏：橙色/金色主光，紫红色阴影
  - 夜晚：深蓝色天光，黑色和蓝色为主

### 2. 角色服装配色服从场景

角色的服装颜色必须和所处场景在逻辑上匹配：
- 金碧辉煌的宫殿 → 角色服装以金色、朱红、深紫等华贵色调为主
- 乡村田野 → 角色穿着朴素，浅色系、棉麻色、土色系
- 森林/自然场景 → 角色服装带有绿色、棕色、大地色系的元素
- 雪山/冰原 → 角色服装以白色、浅蓝、银灰色为主

在prompt中体现：角色三视图可以用中性背景（白底/灰底）生成标准设定图，但在最终合成的视频prompt中，必须在角色描述中加入"衣服/皮肤被[环境光颜色]染色"的描述。

### 3. 共享色调锚点

为同一组素材确定一个"色调锚"短语，所有prompt都写入：
- 例如全组用"暖橙色夕阳色调"，则主体、场景、元素的prompt中都要包含"暖橙色调，夕阳光照"
- 这保证即梦对每张图的色彩倾向理解一致

### 4. 共享风格锚点

为同一组素材确定一个"风格锚"短语（如"日系动漫风格，清晰描边，平涂上色"），在主体、场景、辅助元素的每条prompt中都写入完全相同的风格锚。

### 5. 光源方向统一

所有prompt指定同一光源方向（如"主光源从画面左上方照入"），确保角色的受光面/阴影面与场景一致，合成后不会出现"角色和背景的光打反了"。

### 6. 质感档位统一

所有prompt中对细节的描述保持同一档位：
- 2D动漫/卡通：全部用清晰描边、平涂色块、简洁阴影
- 3D动画：全部用圆润3D造型、柔和全局光照、干净表面光泽
- 写实：全部用真实材质纹理、复杂光影
- 绝不跨档位混搭

### 7. 避免风格冲突词

- 2D动漫/卡通路线：不得出现"写实摄影""CG电影质感""真实材质纹理""3D渲染"等词
- 3D动画路线：不得出现"描边""平涂""赛璐璐""写实摄影""照片级真实"等词
- 写实路线：不得出现"泡泡玛特""Q版""描边""平涂""卡通"等词

## 外源共识·「雪山救狐狸 / 酱板鸭」网红短剧复刻清单（2026）

> **用途**：当用户明确要"和网上视频高度相似/复刻网红短剧"，用本清单把镜头、布景、调色、节拍对齐到大众传播版本，而不是写成通用电影化镜头。**台词仍以用户定稿为准**；本清单只管画面/运镜/声画节奏与邵氏棚景质感。
>
> **交叉引用**：`jimeng-core-delivery.mdc` 的「单段 ≤15 秒 + 镜内时间轴」与「禁止平均分段占位」。

**多源共同点（可执行版）：**

1. **邵氏棚景 + 特艺彩色**：摄影棚假景（假雪山/假院落/假木屋），高饱和特艺彩色，老胶片颗粒，略舞台化布景。
2. **红蓝补色与硬光**：常见"冷蓝环境光 + 暖红/暖黄局部光"强对比；硬光打出明显阴影与轮廓（更像戏曲舞台灯而非自然散射）。
3. **机位偏稳，变焦当情绪**：整体以固定机位/稳定器微动为主；关键笑点/转折常用"邵氏式快速推近/骤然变焦/轻微荷兰角"制造戏剧性。
4. **景别链**：开场用全景/中景建立（雪地、门口、院落），对话用中景正反打，笑点或关键信息用近景/特写"反应镜"停一拍。
5. **一镜一主运动 + 语气停顿**：同一条 4–15 秒里动作主线单一；在台词落点前后留短停顿，让反差成立。
6. **门框纵深锚点**：室内/庭院常用门框、廊柱、院门形成纵深框景；人物多站在门口逆光剪影位，增强"登门问罪/报恩"仪式感。
7. **雪与风做动效**：雪天段必写"风卷雪粉/脚踩雪咯吱/呼气白雾"，让假景也像真景；雪是前景遮挡层与节奏层。
8. **道具特写做梗**：错位道具（如酱板鸭/练习册）必须给"清晰可读"镜头（近景或中近景推近），并配一声"锵/噔"的戏剧点音。
9. **武侠音效与管弦底**：常见"锵锵/门轴吱呀/风雪声/钱币哗啦/兵器金属声"与低量武侠管弦底；声画同步写进镜头句。
10. **人物表情分步**：常见"惊→愣→转喜→求饶""冷→压怒→爆发"分步，用短时间码写在 prompt 里。
11. **反差策略**：画面越认真（武侠正经、灯光正经），台词越荒诞（必刷题/AI/Token），反差越好笑；不要把画面写成"搞笑风"。
12. **拆条优先级**：长对白/口型密集段优先拆成两条 ≤15 秒，分别保证口型与反应镜稳定，再剪辑成网短剧节奏。

## 运镜技巧（Seedance 2.0 专业运镜）

Seedance 2.0 能准确响应专业电影摄影术语。运镜描述越具体（类型+速度+轨迹），执行越精准。避免模糊的"镜头移动"，要写明具体的运镜方式。

### 运镜三要素

1. **运镜描述**：控制镜头感觉与类型
   - 稳定性：平稳的、手持晃动的、呼吸感微动的、丝滑流畅的
   - 速度：缓慢的、匀速的、变速的（写明时长更精准，如"8秒内缓慢推入"）
   - 高度：低角度的、平视的、俯视的、仰视的
   - 类型：见下方专业运镜速查表

2. **跟随对象**：镜头跟随的主体（仅在有跟随需求时写）

3. **开头→结尾动态变化**：经过哪里、到达哪里，包含场景/光线/焦点变化

### 难角度辅助：补写该角度下的可见元素

> **原理**（视觉代偿）：AI 不真正理解「俯拍」「仰拍」「背影」等抽象空间指令。它是通过渲染**在那个角度应该看到的具象元素**来间接实现构图的。因此，写景别/角度词的同时，**补写该角度下镜头能看到的具体物件**，会显著提高角度执行准确率。这是景别词的**辅助加固手段**，两者叠用最稳。

| 目标角度 | 景别/运镜词（主控） | 补写的可见元素（辅助加固） |
|---------|-------------------|-------------------------|
| **仰拍** | 低角度仰拍 | 下巴轮廓、鼻孔微露、天花板/天空/树冠、从下往上看到的建筑立面 |
| **俯拍** | 高角度俯拍 / 鸟瞰 | 头顶发旋、肩膀轮廓、地面纹理/脚印、桌面物品俯视布局 |
| **背影** | 背面镜头 | 后脑勺、脊背线条、背包/发尾/衣领后缘、人物前方的环境（走向的方向） |
| **侧面** | 侧面镜头 | 侧脸轮廓（鼻梁、下颌线）、耳朵、侧面肩线、身体纵深 |
| **极低贴地** | 贴地仰拍 / 虫视角 | 鞋底/脚掌、地面裂缝/草叶/水洼倒影、人物从脚到头的纵深透视 |
| **特写** | 面部特写 / 细节特写 | 瞳孔纹理、睫毛、毛孔、嘴唇纹路（大量面部细节词会引导模型自动拉近镜头） |
| **远景/全景** | 大远景 / 全景 | 天际线、建筑群轮廓、地面延伸到远处的道路/河流（大量环境词引导模型自动拉远） |

**使用方法**：在写运镜词之后，追加 1-2 个该角度的可见元素即可，不需要全部堆上。例如：「低角度仰拍，可以看到人物下巴轮廓和身后的天空」比单独写「仰拍」更稳定。

## 多镜头分镜与节奏控制（重要）

视频关键词不是写一段话就结束，而是要拆分为多个镜头，每个镜头标注时长、景别、运镜，形成完整的分镜表。Seedance 2.0 单次生成支持 **4-15秒**，可在一次生成中实现多镜头叙事。

### 景别叙事逻辑速查（先选景别，再定运镜）

> **外源交叉**：抖音「一帆 · AI 视听语言」系列；[Filmmakers Academy · Camera & Emotion](https://www.filmmakersacademy.com/blog-camera-emotions-techniques/)；[伪字性 · 15 种镜头角度](https://www.douyin.com/)。

景别不只是"拍多大"，而是**用画面引导观众按顺序接收信息的叙事工具**。把所有信息塞进一个景别，观众什么都抓不住；按叙事目的拆成不同景别，观众才会跟着你的节奏走。

| 叙事目的 | 首选景别 | 为什么 | 提示词写法要点 |
|---------|---------|--------|--------------|
| **建立世界 / 交代地点** | 大远景 / 全景 | 让观众先知道故事发生在哪里，感受空间规模 | 重点写环境元素（建筑、地形、天气、光线），人物可以很小或不出现 |
| **交代动作 / 引入角色** | 中景（腰部以上） | 观众开始关注"这个人在做什么"，动作和位置关系清晰 | 重点写人物动作和与环境的互动，景别刚好看清动作但不丢环境 |
| **传递情绪 / 反应** | 近景（胸部以上） | 表情和眼神成为画面核心，观众开始感受角色的内心 | 重点写表情、眼神、微表情变化，环境退到虚化背景 |
| **放大细节 / 转折点** | 特写 / 大特写 | 一个具体的细节（手、眼睛、物件）被放大，引导观众注意关键信息 | 重点写局部细节（手指动作、眼球变化、物件纹理），其余全部虚化 |
| **人物出场（英雄感）** | 低机位仰拍 → 缓慢抬升至面部 | 从下往上积累力量感，镜头抵达面部时完成英雄亮相 | 先写脚/腿/身体轮廓，再写抬升到面部，最后写表情 |
| **人物出场（悬念感）** | 背面 → 缓慢环绕至正面 | 先看轮廓和环境，制造好奇心，再揭示正脸 | 先写背影/剪影/环境元素，再写镜头绕到正面 |
| **对话（建立关系）** | 双人中景 | 两个角色同框，看清位置关系和互动 | 写清两人的相对位置和各自动作 |
| **对话（强化情绪）** | 过肩反打 / 近景交替 | 让观众站在一个角色的位置看另一个角色说话，代入感强 | 每条只写一个角色的近景反应，交替生成后剪辑衔接 |
| **环境压迫感** | 鸟瞰 / 极高俯拍 | 人物渺小 vs 环境庞大，形成视觉压迫 | 大量写环境规模，人物只占画面很小比例 |
| **临场感 / 刺激感** | POV / FPV 第一人称 | 观众变成角色本身，沉浸在场景中 | 写清"第一人称视角"，描述镜头穿越的空间和速度感 |

#### 镜头角度 = 情绪本身（外源交叉·伪字性 15 种镜头角度 + 一帆视听语言）

> 同一个人物，镜头角度不同，观众感受到的情绪强度**完全不同**。镜头角度不只是摄像机的物理位置，是电影中最重要的叙事工具之一。

| 镜头角度 | 传递的情绪 | 什么时候用 | 提示词写法要点（含可见元素辅助） |
|---------|----------|-----------|-------------------------------|
| **平视** | 中性、客观、平等、日常 | 对话、日常叙事、默认选择 | 「平视镜头，与人物视线同高」——注意：如果所有镜头都用平视，画面会**很普通** |
| **低机位仰拍** | 力量、英雄、威严、压迫 | 人物出场、展示权威、boss登场 | 「低角度仰拍，可以看到人物下巴轮廓和身后的天花板/天空」 |
| **贴地仰拍（虫视角）** | 极致力量感、神降临、恐惧源 | 巨物出场、极致压迫、力量对比 | 「镜头贴近地面向上仰视，前景是地面纹理/鞋底，人物从脚到头形成纵深透视」 |
| **高角度俯拍** | 渺小、脆弱、被审判、控制 | 角色陷入绝境、被审视、失败 | 「高角度俯拍，可以看到人物头顶发旋和肩膀轮廓，人物显得渺小」 |
| **鸟瞰（正俯90°）** | 上帝视角、全局、规模、对峙 | 展示战场全貌、空间关系、角色对峙 | 「正上方鸟瞰俯拍，可以看到地面纹理和人物的微小轮廓」 |
| **背面镜头** | 孤独、悬念、未知、即将面对的世界 | 角色面对未知、独行、悬念出场 | 「镜头在人物身后，可以看到后脑勺、脊背线条和人物前方的[环境]」 |
| **侧面镜头** | 沉思、压抑、欲言又止、冷静 | 角色思考、犹豫、不想被看穿 | 「侧面镜头，可以看到侧脸轮廓、鼻梁和下颌线，部分表情隐藏在阴影中」 |
| **倾斜/荷兰角** | 心理失衡、不安、世界扭曲、紧张 | 精神失控、恐怖、世界观崩塌 | 「画面倾斜约15-20度，水平线歪斜」—— Seedance 中需实测稳定性 |
| **POV第一人称** | 沉浸、临场、代入 | 观众=角色、主观体验、发现某物 | 「第一人称视角，镜头模拟人物目光看向[具体对象]」 |
| **过肩镜头** | 亲密、对话代入、空间关系 | 对话、对峙、一方审视另一方 | 「镜头在[A]肩膀后方，前景是[A]肩膀和后脑勺的虚化轮廓，焦点在[B]脸上」 |

**核心原则**：写每个镜头前，先问自己"这个角度要传递什么情绪？"——如果答案是"没想过"，说明你在机械堆画面而非用镜头叙事。

#### 人物出场模式详解（从景别表展开的实操指南）

> **外源交叉**：抖音「伪字性 · 15 种镜头角度」人物出场篇；「一帆 · AI 视听语言」景别篇。

上表列出了"英雄感"和"悬念感"两种出场，实操中至少掌握**三种出场模式**，根据叙事需要选择：

| 出场模式 | 镜头语言 | 传递什么 | 提示词写法要点 |
|---------|---------|---------|--------------|
| **英雄感出场** | 低机位从脚部开始缓慢仰拍抬升，经过腿部、腰部、胸部，最终停在面部 | 力量感、压迫感、权威、可靠 | 先写鞋/脚→腿→身体轮廓→最后写面部表情；补写下巴轮廓和身后天空/建筑 |
| **悬念感出场** | 背面镜头开始，利用门框/纱/前景遮挡构图，缓慢环绕至侧面再到正面 | 神秘、好奇、未知、期待 | 先写后脑勺/脊背/剪影→前景遮挡元素→镜头缓慢绕到侧面→最后揭示正脸 |
| **故事感出场** | 平视+跟拍+环绕，同时展现人物和环境的互动关系 | 融入世界、角色与环境的关系、为后续剧情埋伏笔 | 同时写人物动作和环境细节，镜头跟随人物移动并扫过环境元素 |

**关键原则**：出场镜头的信息要**逐步释放**——先给轮廓/环境制造悬念，再揭示全貌。一上来就全景正面平视拍出全部信息 = 浪费了出场的叙事机会。

#### 对话镜头升级路径（从平淡到有感染力）

> **外源交叉**：抖音「伪字性」对话镜头篇；电影「正反打」与「过肩反打」比较。

对话场景不要从头到尾只用一种景别，应按情绪升级路径**逐步切换**：

| 阶段 | 景别 | 目的 | 什么时候用 |
|------|------|------|-----------|
| **建立空间关系** | 双人中景（两人同框） | 让观众看清两人位置关系和环境 | 对话开始的前几秒 |
| **用背景强化对白** | 高位下降镜头 or 背面绕到正面 | 先展现环境→绕到人物，用环境信息强化台词的情绪 | 台词内容与环境有关时 |
| **用对白强化背景** | 先交代人物关系再展现环境 | 台词先出，环境后出，环境成为台词的视觉注脚 | 需要用环境元素增强紧张感/危险感时 |
| **强化情绪互动** | 过肩反打（OTS Reverse） | 让观众站在一个角色的位置看另一个角色说话，代入感最强 | 对话进入具体交流、情绪升温时 |
| **最大情绪冲击** | 近景/特写交替 | 只看一个人的微表情反应，环境完全虚化 | 关键台词落点、情绪爆发、转折时刻 |

**180° 法则**：在两名角色之间设一条虚拟轴线，镜头始终保持在轴线同一侧拍摄，保证角色"左右关系"不混乱。过肩反打时：A 在画面左侧肩膀后方看 B，切换后 B 在画面右侧肩膀后方看 A——**左右不能反**。

**30° 法则**：连续切换同一主体的镜头时，摄影机至少移动 30° 角度。移动不足 30° 会产生"跳切"（看起来像画面 bug）。若同时配合景别变化（如中景→特写），衔接会更流畅。

**经典叙事链**：远景建立 → 中景引入 → 近景情绪 → 特写转折 → 远景收束。单条 15 秒内可用「切换至」串联 2-3 个景别；跨条时每条锁一个景别更稳。

### 时长选择策略

| 时长范围 | 适用场景 | 优势 |
|---------|---------|------|
| 4-7秒 | 单一动作、反应镜头、空镜头 | 一致性高，漂移少，生成快 |
| 10-15秒 | 多镜头序列、叙事弧、复杂编排 | 节奏自然，有转换空间 |

需要更长内容时：生成15秒片段，将上一段的最后一帧作为下一次生成的参考图，创建无缝延伸（详见 `jimeng-workflows.mdc` → B 节「多段视频」）。

### 同一条（4-15秒）内时间码分配原则

**禁止默认「三等分」**（如 5+5+5）：容易让建立镜头过短、冲击镜头拖塌、台词镜头抢戏失败。

| 镜头功能 | 建议占整条的比例（以10-15秒为例） | 说明 |
|---------|----------------------------------|------|
| **环境建立 / 大远景 / 铺垫** | **约 40%-55%**（常 ≥6 秒） | 观众需要时间识别空间与情绪；过短会立刻跳进下一镜，叙事像「赶场」 |
| **高速冲击 / 跟拍飞行物 / 斩击** | **约 15%-30%**（常 2-4 秒有效动感即可） | 靠密度取胜：景别、速度线、音效陡升，而不是拉长时间 |
| **台词 + 表情 / 反应** | **约 25%-40%**（常 ≥4 秒） | 嘴型与微表情需要停留；与上一镜之间可用「声画骤变」制造节奏对比 |

若单条内要容纳「远景建立 + 跟箭 + 人物近景台词」三段，仍觉拥挤：**拆成两条视频生成**（第一条只做战场建立，第二条箭→人），比硬塞在一条15秒内更稳、更少崩坏。

### 单镜头prompt规则

每个镜头的prompt只描述该镜头时长内能完成的动作，不贪多：
- 3-4秒镜头：一个动作或一个表情变化
- 5-7秒镜头：一个动作 + 环境反应
- 不要在一个镜头prompt里塞一整段剧情

### 高速运动物体与冲击感（箭矢、投掷物、轨迹线）

「缓慢横移 + 箭飞过」若只写这一句，容易像幻灯片。**冲击力至少命中下列 3 条：**

1. **景别**：以**近景/特写**跟箭头或箭身为主，或**急速推镜 Crash In**扑向飞行物；避免整条只有远景里一根细线
2. **画面动感**：**速度线、气流、残影、画面边缘径向模糊**；接触前可加**极短慢动作**再切回常速
3. **声画陡变**：破空声**尖厉短促**；BGM **骤强或骤停**与前镜形成对比；前镜越静，本镜越响越有效
4. **前一镜铺垫**：建立镜用**慢、远、低音铺垫**，再切跟箭，张力才拉得开
5. **简易道具**：箭的外观在句内写全，**不必**（参考@箭道具图）；复杂神器再单独出图

### 叙事堆叠与崩坏风险（单条15秒内）

同一条生成里若同时写：**远景建立 + 箭矢轨迹 + 脚跟/裸足特写 + 中箭/撞击**，模型常**压缩前半段**、快进到训练数据里的「名场面」，并放大**脚趾畸形、箭与身体前后关系错误**等崩坏。

**缓解**：① **拆条**——战场建立单独一条；箭→人物单独一条；② **单条内减少关键词堆叠**——建立镜不写箭不写脚；③ **尽量避免裸足脚跟大特写**，或穿鞋甲降低脚部模型压力。

### 分镜格式

单次生成最多3个镜头。每个镜头写成一段连贯的文字，@引用、台词、音效自然穿插在画面描述中。镜头之间**默认**用 **「切换至」或「硬切至」** 标记硬切边界；需要柔和过渡时可写 **「过渡至」**。仅在用户要求时使用英文 `Cut to` / `Transition to`，防止独立镜头间被模型糊成过度平滑的衔接。

**默认必须**使用时间码标记（推荐两种任选其一）：`[00:00-00:05]` 或 `[0s-5s]`，精确控制每个动作的时间点与切镜位置。

```
[00:00-00:07] 镜头1：景别运镜 场景描述（参考@场景图）角色出场（参考@主体三视图）动作和音效和台词自然穿插 氛围和BGM情绪 风格锚 色调锚 画质约束。切换至 [00:07-00:10] 镜头2：……（简易道具仅文字描述，不写@道具图）
```

### 一体化写法规则

所有要素融合为一段自然语言，@引用在角色/物件/场景第一次出现时紧跟其后：

1. 时间码（必填）和景别运镜开头，运镜用中文术语（如"中景缓慢推镜"）
2. 场景环境出现时跟上@场景图（如"天宫废墟（参考@场景图）"）
3. 角色出现时跟上@主体（如"少年猴王（参考@主体三视图）"）
4. **道具**：默认只在句内用文字描述外观与材质，**不**写 `@道具图`。**仅当用户已要求并生成了道具参考图**时，复杂道具可写（参考@神器设计图）等；简易道具仍优先纯文字
5. 同一镜头内同一素材只需@一次，后续再出现不重复@
6. 台词直接融入动作描述（如"猴王怒吼哈"）
7. 音效融入场景和动作描述（如"火焰噼啪作响""棒身划出尖锐破风声"），Seedance 2.0会自动生成匹配音效
8. BGM情绪融入氛围描述（如"低沉弦乐渐转为热血鼓点"）
9. 风格锚和色调锚
10. 末尾写画质与防崩约束词（固定后缀，每个镜头都要加）
11. 镜头之间**默认**用 **「切换至」「硬切至」** 标记转换（用户指定时可用 `Cut to`）

### 画质与防崩约束词（必加后缀）

每个镜头prompt末尾必须附加质量约束词，防止画面崩坏和畸变。Seedance 2.0对稳定性关键词响应良好：

**正向质量词**（告诉AI要什么质量）：
`4K超高清 画面稳定 动作流畅自然 细节清晰锐度高 人体结构正确 关节自然弯曲 电影质感 色彩自然 光影柔和`

**负向约束词**（告诉AI不要什么）：
`无畸变 无多余肢体 无多余手指 无缺少手指 无粘连手指 无畸形手部 无断裂肢体 无漂浮肢体 无模糊 无闪烁 无重影 人物比例正确 背景稳定不跳变 禁止生成字幕 禁止生成屏幕文字 禁止生成标题文字 禁止生成水印`

**Seedance 2.0 稳定性关键词**（额外焊死在末尾）：
`五官清晰 面部稳定不变形 人体结构正常 比例自然 动作不僵硬 同一角色 服装一致 发型不变`

合并为固定后缀模板，直接接在风格锚色调锚之后：
```
4K超高清 画面稳定 动作流畅自然 细节清晰 电影质感 人体结构正确 关节自然弯曲 五官清晰 面部稳定不变形 无畸变 无多余肢体 无模糊 无闪烁 无重影 人物比例正确 背景稳定 禁止生成字幕 禁止生成屏幕文字 禁止生成标题文字 禁止生成水印
```

根据画面内容可追加针对性约束：
- 有人物时追加：`五官对称 面部比例真实 表情自然 手指五根数量正确 手部结构清晰 四肢完整`
- 有剧烈运动时追加：`运动轨迹连贯 无肢体扭曲 无肢体拉伸变形 动作符合人体工学`
- 有多角色时追加：`角色外观前后一致 服装颜色不变 每个角色肢体独立不粘连`
- 需要额外稳定时追加：`丝滑流畅 无抖动 无卡顿 画面稳定不跳变`

### 即梦负向提示词设置

除了在prompt正文中写入约束词外，还应在即梦的**高级设置 → 负向提示词/排除内容**输入框中填入以下内容，双重保险：

```
畸形 变形 多余手指 缺少手指 粘连手指 多余肢体 断裂肢体 漂浮肢体 面部扭曲 五官不对称 人物比例失调 模糊 低质量 水印 噪点
```

### 人物姿势防崩技巧

某些姿势比其他姿势更容易生成稳定的结果，在设计角色动作时优先选择稳定姿势：

**稳定姿势（优先使用）**：
- 双手自然垂放身体两侧
- 双手背在身后
- 单手握住一个物品（武器、杯子等，物品锚定手部形态）
- 双手插兜 / 抱胸
- 手掌撑在桌面或扶手上

**高风险姿势（尽量回避或简化描述）**：
- 十指交叉
- 比心、剪刀手等精细手势
- 多人握手/牵手
- 手指指向特定方向
- 手部大面积特写（除非画面核心需要）

**降低崩坏率的描述技巧**：
- 用物品锚定手部：让角色手持道具，比空手更稳定
- 避免肢体重叠：两只手臂不交叉、腿不缠绕
- 具体化身体位置：写明"左手握剑 右手自然垂放"而非"手里有把剑"
- 单镜头单动作：一个镜头只安排一个主要动作，不堆砌连续动作

### 关键词联想陷阱（特征污染的语义层面）

> **外源交叉（2025–2026）**：抖音「大师」系列（关键词联想陷阱 & 视觉代偿）；arXiv [Negation Blindness · The NO Syndrome](https://arxiv.org/abs/2409.00105)；arXiv [Contextually Contradictory Prompts](https://arxiv.org/html/2506.01929v2)；Ideogram [Handling Negatives](https://docs.ideogram.ai/using-ideogram/prompting-guide/4-handling-negatives.md)；[Seedance 2.0 Troubleshooting](https://www.bigmotion.ai/user-guide/seedance-2-0-tips-troubleshooting)。

#### 原理

AI 生成模型会把提示词拆成**词块**逐个理解，对每个词块激活训练数据中与之关联最强的视觉特征。这导致两类隐性 bug：

1. **联想陷阱**：提到某个词，模型自动拉出一整套刻板印象。即使你写「不要」「禁止」，模型仍然**先激活了该词的视觉特征**再试图抑制，结果往往抑制失败（学术界称为 Negation Blindness / The NO Syndrome）。
2. **视觉代偿**：模型无法理解「背对」「望向」等抽象空间概念，会用**具象元素**补偿——要表达「背身」就画出脊背和背包，要表达「望向」就画出眼睛和正脸。两个矛盾的代偿同时出现时，模型只能折中（比如侧身），导致构图跑偏。

#### 高频污染场景速查表

| 你写的 | AI 实际做了什么 | 为什么 | 正确改写 |
|--------|----------------|--------|----------|
| 男生在**打游戏** | 手机屏幕反转面向镜头、人物反向拿手机 | 「游戏」触发「必须让观众看到游戏画面」的联想 | 「男生双手横向拿着手机，目光专注看向屏幕」——去掉「游戏」污染源 |
| 人物在电脑上**修图** | 显示器翻转面向镜头 | 「修图」触发「必须展示屏幕内容」 | 「男生坐在桌前，目光看向显示器正面，双手放在键盘上」 |
| 戴**护士帽** / 不戴护士帽 | 穿护士服 + 出现在医院 | 「护士帽」激活全套护士刻板印象，否定词无效 | 如果只要帽子：「女生戴一顶白色软帽，穿[你要的服装]，站在[你要的场景]」——彻底不提「护士」 |
| 戴**厨师帽** / 不戴厨师帽 | 出现在后厨、手持锅铲 | 同上，「厨师」拉出全套 | 同上，用帽子外观描述替代职业名词 |
| 宇航员**背对镜头望向**地球 | 侧身或正脸 | 「背对」需画脊背，「望向」需画眼睛/正脸，两者矛盾后模型折中 | 「一个宇航员站在月球表面，脊背朝向镜头，远方太空中悬浮着一颗地球」——只描述可见元素，不写「望向」 |
| 老师面对**学生**讲课 | 学生转身面对镜头、背对老师 | 提到「学生」后模型激活「学生正脸」特征，与「面对老师」矛盾时优先把脸转向镜头 | **方法一**：把镜头锚定为教室后方视角——「镜头从教室后排拍向讲台方向，老师站在讲台上面向镜头讲课，前景是几排学生的后脑勺和肩膀」；**方法二**：用空间锚点绑定朝向——「学生坐在课桌前，面朝讲台方向，老师站在黑板前面向学生」，用「讲台」「黑板」做方向参照系而非抽象的「面对」 |
| 海滩上**没有人** | 仍然出现人 | 「人」被激活，否定词失效 | 「空旷的沙滩，只有海浪和脚印，远处是无人的礁石」——用正向的「空旷」替代否定 |
| 龙在**喷水** | 龙喷火 | 「龙」与「火」的训练关联远强于「水」 | 「一条蓝色巨龙张开嘴，一股湍急的水流从口中涌出，水花四溅」——用大量水的具象描述压过火的默认联想 |

#### 通用改善措施（写提示词时的四条检查）

1. **消灭否定词**：把所有「不要 XX」「禁止 XX」「没有 XX」改写成**正向替代**。
   - 「不要模糊」→「画面锐利清晰」
   - 「没有人」→「空旷的、无人的」
   - 「不戴帽子」→ 直接不提帽子，只写你要的发型

2. **拆除职业/场景名词，改用外观描述**：当你只需要某个元素（如一顶帽子、一件外套）而不需要全套刻板印象时，**不写职业名词**，改用颜色+形状+材质描述。
   - 「护士帽」→「白色软布圆帽」
   - 「消防员的外套」→「厚实的深黄色防火面料外套，反光条纹」

3. **用空间锚点替代抽象方向词**：当需要控制人物朝向时，**不写**「面对」「背对」「望向」，改为**用场景中的具体物件做参照系**。
   - 「学生面对老师」→「学生坐在课桌前，面朝讲台和黑板方向」
   - 「背对镜头」→「脊背朝向镜头，后脑勺可见」
   - 「望向远方」→「目光平视前方，远处是[具体景物]」

4. **用可见元素控制镜头远近（视觉代偿反向利用）**：想要特写就大量描述面部细节（毛孔、睫毛、瞳孔纹理），想要远景就大量描述环境元素（建筑轮廓、天际线、地面纹理），模型会自动分配像素给描述最密集的区域。这是景别词的**辅助加固手段**，尤其在景别词不稳定时有效。

### 台词规则

- 台词内容由用户提供（在需求澄清阶段询问）
- 台词直接写进画面描述中，如"少年猴王怒吼哈""女孩轻声说了句谢谢你"
- 不用引号不用括号不用标注语气标签，语气通过动作和修饰词自然表达
- 无台词的镜头不写，不强行加

### 角色声音与语气控制（Seedance 2.0 原生音频）

Seedance 2.0 的原生音画同步能根据提示词中的声音描述生成匹配的角色音色和语气。**不写声音描述 = 让AI随机分配声音，效果不可控**。以下关键词体系能显著提升生成声音的质量：

#### 角色首次出场时定义声音

角色第一次出现时，用括号标注年龄+音色+情绪特征，让模型区分不同角色的声音：

```
少年猴王（十五六岁少年，声音清亮带野性，说话带不羁的笑意）
老师傅（六十多岁老者，声音低沉浑厚，语速缓慢沉稳）
小女孩（七八岁，声音稚嫩清脆，好奇心重，语调上扬）
```

#### 音色特征关键词

| 关键词 | 效果 | 适配角色 |
|--------|------|---------|
| 低沉的声音 / deep voice | 浑厚有力 | 成年男性、威严角色、boss |
| 清亮的声音 / clear bright voice | 明亮干净 | 少年、年轻女性 |
| 沙哑的声音 / husky voice | 磁性、沧桑 | 经历丰富的角色 |
| 温暖的声音 / warm voice | 柔和亲切 | 母亲、治愈系角色 |
| 稚嫩的声音 / childish voice | 童声、天真 | 儿童角色 |
| 洪亮的声音 / booming voice | 威严、震慑 | 将领、神明、权威角色 |
| 柔软的声音 / soft voice | 轻柔细腻 | 温柔角色、安慰场景 |
| 粗砺的声音 / gravelly voice | 粗犷沧桑 | 战士、反派、老兵 |

#### 语气情绪关键词

将语气融入动作描述，不要单独列出：

| 写法 | 效果 |
|------|------|
| 兴奋地喊出 / says excitedly | 语速快、音调高、有感染力 |
| 低声耳语 / whispers | 气声、音量极低、亲密或紧张 |
| 怒吼 / shouts angrily | 音量大、咬字重、情绪爆发 |
| 平静地说 / says calmly | 语速慢、稳定、不带波动 |
| 喃喃自语 / murmurs | 含糊、低声、自言自语 |
| 自豪地说 / says proudly | 底气足、音调微扬 |
| 悲伤地说 / says sadly | 音调低沉、语速放慢、声音微颤 |
| 紧张地说 / says nervously | 语速不稳、有停顿犹豫 |
| 坚定地说 / says with determination | 咬字清晰、节奏有力 |
| 叹了口气说 / sighs and says | 先叹息声再出语 |
| 停顿了一下说 / pauses before saying | 制造悬念或犹豫感 |

#### 声音描述的正确融入方式

**错误写法**（声音和画面割裂）：
```
角色在公园里。音频：开心的声音说太好了。
```

**正确写法**（声音融入画面动作）：
```
女孩眼睛猛然睁大嘴角上扬 兴奋地喊出来太好了 声音清亮带笑意尾音微微上扬
```

#### 多角色对话的声音区分

多角色对话时，每个角色的声音必须有明显区分，否则AI会生成相似的声音：

```
少年猴王（十五六岁 声音清亮不羁）纵身跃起怒吼哈 
老神仙(白须老者 声音低沉浑厚 语速缓慢)平静地说急什么
```

#### 声场空间描述

不同场景空间会影响声音的回响和质感，描述声场能提升音频真实感：

- **空旷大厅/洞穴**：加"声音在墙壁间轻微回荡"
- **密闭小空间**：加"声音紧贴近距离感 无回声"
- **室外开阔地**：加"声音清晰但被风声稀释 远处有环境音"
- **雨天/水边**：加"说话声混在雨声中 需要提高音量"

#### 音频负向约束

在需要高质量音频时，可追加音频约束词：

```
无失真 无机器人音质 无突兀的声音剪切 无回声瑕疵 对话声音清晰突出
```

#### 音频最佳实践

1. **每个片段聚焦一个音频重点**：对话场景突出台词+环境音，不加复杂配乐；建立镜头突出环境音+配乐，不加台词
2. **台词写短句**：短句的唇形同步比长句准确得多
3. **音频能量匹配画面**：高能动作配激烈音效，安静画面配安静音频，不要冲突
4. **用现实世界的声音参照**：如"像深夜电台主播的声音""雨打铁皮屋顶的声音"，模型对具象参照响应更好

### 音效与配乐规则

Seedance 2.0 原生音画同步会自动生成匹配音效，但显式描述能大幅提升音效质量。音效自然融入描述中而非单独列出：

#### 三层音频结构

每个镜头的音频由三层组成，按重要性排序，**每个镜头聚焦一个主要音频层**：

1. **台词/对话**（最高优先级）：角色说话的内容和方式
2. **动作音效/环境音**（中优先级）：画面中发生的声音
3. **BGM/配乐**（最低优先级）：背景音乐情绪

#### 音效写法

- 环境音写进场景描述（如"远处火焰噼啪作响 风卷过废墟发出呼啸"）
- 动作音效写进动作描述（如"金箍棒划出尖锐破风声击中石柱发出沉闷撞击"）
- BGM情绪写进氛围描述（如"低沉弦乐渐渐转为热血激昂的鼓点节奏"）

#### 配乐描述技巧

不要只写"有音乐"，要具体描述风格、节奏和情绪关系：

```
背景配乐：低沉钢琴单音缓慢弹奏 节奏舒缓 传递沉思和宁静感 音量低于角色对话
```

```
鼓点骤然加速与角色挥棒动作同步 节奏热血激昂 在角色落地瞬间音乐骤然安静只留余韵
```

#### 音频转场

如果镜头中有声音环境变化，显式描述转场效果：

```
画面从安静的图书馆推开门走到喧闹的街道 声音从压低的耳语和翻书声突然切换为嘈杂车流和行人喧哗
```

### 物理感知动作描写（Seedance 2.0 强项）

Seedance 2.0 的物理模拟引擎能理解重力、碰撞、材质弹性等物理规律。用物理细节替代模糊描述，能显著提升动作的真实感和冲击力。

**物理描写公式**：动作 + 力学反应 + 材质响应 + 环境连锁

**通用动作 → 物理增强对照表**：

| 模糊写法 | 物理增强写法 |
|---------|------------|
| 物体从架子上掉下来 | 玻璃瓶依次从架子上翻滚而下，撞击地面时粉碎，碎片以真实的动量向外散射 |
| 织物在风中移动 | 丝绸织物在风中翻腾起伏，轻质材料捕捉空气后漂浮，随后较重的边缘先下坠 |
| 角色被击飞 | 角色身体因冲击力后仰，重心失衡向后倒退数步，脚下泥土被蹭出痕迹 |
| 碎片飞溅 | 碎石以放射状轨迹被气浪弹飞，大块碎片先落地弹跳，细碎颗粒在空中缓慢飘散 |
| 衣服飘动 | 衣袍下摆因急停的惯性继续向前甩动，随后缓缓回落贴合身体 |

**不同场景的物理细节重点**：

- **战斗/动作场景**：打击接触的力学反馈（冲击波、地面碎裂、碎片散射方向）、武器的重量感（挥动的惯性、击中后的反震）
- **自然/环境场景**：风对不同材质的差异化影响（轻纱翻飞 vs 厚布微动）、水面的波纹扩散、烟尘的上升与消散
- **日常/生活场景**：倒水时液面的晃动、翻书时纸页的弹性回弹、发丝的自然飘动

### 不同场景类型的镜头时长参考

| 场景类型 | 单镜头时长 | 切镜频率 | 说明 |
|---------|-----------|---------|------|
| 战斗/动作 | 3-4秒 | 快切 | 短促密集，速度感强，可用速度线和残影 |
| 情感特写 | 4-7秒 | 慢 | 留足时间让观众感受表情和情绪 |
| 对话/日常 | 4-7秒 | 中等 | 稳定叙事，正反打切换 |
| 环境建立 | 4-7秒 | 慢 | 远景或全景交代空间，给观众定位感 |
| 高潮爆发 | 3-4秒 | 极快 | 关键帧可放慢（慢动作），前后快切对比 |
| 过渡/喘息 | 4-5秒 | 慢 | 情绪缓冲，为下一波高潮蓄力 |

### 节奏起伏原则

全片节奏必须有起伏变化，不能从头到尾一个速度：

1. **快→慢→快**：战斗场景中穿插一个慢镜头特写（如角色表情），再回到快节奏，形成呼吸感
2. **远→近→远**：远景建立环境 → 中近景推进叙事 → 远景收束或过渡，形成景别节奏
3. **静→动→静**：安静的环境镜头 → 动作爆发 → 动作后的静默瞬间（留白），冲击力最强
4. **开头3秒抓眼球**：第一个镜头用特写+强动作/悬念吸引注意力
5. **环境镜头当标点**：在段落之间用一个环境/空镜头做"呼吸"，如天空、飘落的碎片、风吹过的草地

### 景别切换逻辑

不要连续用同一景别，景别应交替使用形成节奏：

| 景别 | 画面范围 | 适用场景 |
|------|---------|---------|
| 大远景 | 环境为主，角色极小 | 开场建立世界、结尾收束、展现宏大感 |
| 远景/全景 | 环境+角色全身 | 交代场景、展现人物与环境关系 |
| 中景 | 角色膝盖以上 | 对话、日常动作、平稳叙事 |
| 近景 | 角色胸部以上 | 刻画情绪、肢体语言 |
| 特写 | 脸部/局部 | 情感爆发、重要细节、关键道具 |

### 转场方式与剪辑技法（外源交叉·电影剪辑学 + AI视频实操）

> **外源交叉**：Adobe · Cuts in Film；StudioBinder · Match Cuts & Creative Transitions；InVideo · 9 Types of Cuts；Fiveable · Editing for Suspense, Comedy, Dramatic Impact。

转场不是"两段之间的过渡效果"，而是**叙事节奏的标点符号**。选错转场 = 破坏节奏。

#### 基础转场类型

| 转场方式 | 效果 | 适用场景 | 提示词写法 |
|---------|------|---------|-----------|
| **硬切** | 直接跳到下一镜，干脆利落 | 快节奏、动作戏、紧张感、喜剧反差 | 「硬切至」—— 默认首选，最稳 |
| **淡入淡出** | 柔和过渡，暗示时间流逝 | 回忆、抒情、章节切换 | 「画面缓慢淡出至黑……淡入」 |
| **动作接动作（Match on Action）** | 前一镜的运动方向/速度延续到下一镜 | 流畅叙事、追逐、动作连贯 | 前一镜末写运动方向，后一镜首写同方向延续 |
| **匹配剪辑（Graphic Match）** | 前后两镜的构图/形状/颜色相似，视觉无缝 | 隐喻、时间跳跃、主题关联 | 前一镜末写圆形物体特写，后一镜首写另一个圆形物体 |
| **声画预叙（J-Cut 效果）** | 下一镜的声音先于画面出现 | 建立期待、制造悬念、对话场景衔接 | 前一镜末写"远处传来[下一场景的声音]"，再硬切到下一画面 |
| **声画延续（L-Cut 效果）** | 前一镜的声音延续到下一画面中 | 延伸情感、暗示时间、对话过渡 | 后一镜首写"前一场景的[声音/台词]仍在回响"，画面已切新场景 |
| **声画陡变（Smash Cut）** | 从一个极端突然跳到另一个极端 | 喜剧反差、惊吓、打破预期 | 「——声画骤变——硬切至」配合画面/音量的极端反差 |
| **交叉剪辑（Cross-Cut）** | 交替展示两个同时发生的事件 | 建立张力、暗示对比、悬念升级 | 拆为两段交替生成后剪辑 |

#### Seedance 侧注意

- Seedance 单条生成最稳的转场是**硬切**（「硬切至」「切换至」），模型对硬切边界的执行最清晰
- 声画预叙/延续效果在 Seedance 单条内**可部分实现**（写前一镜末尾出现下一场景的声音），但跨条时建议**后期剪辑实现**
- 匹配剪辑在 AI 视频中较难精确控制，建议**前后镜分别生成**，在剪辑软件中对齐构图

#### 节拍控制（Pacing）

| 技法 | 效果 | 怎么用 |
|------|------|--------|
| **拉长时间（Elongating Time）** | 放大戏剧张力，让关键时刻"慢下来" | 同一事件从多个角度拍（如敲桌子：先拍手、再拍被敲者反应、再拍旁观者反应），拆多镜拉长感知时间 |
| **在动作上切（Cut on Action）** | 让转场隐形，观众注意力跟着动作走 | 前一镜角色开始转头，后一镜从另一角度接着转头的尾部 |
| **人为停顿（Artificial Pause）** | 放大情绪重量 | 反应镜头比正常时长多停留1-2秒，让"一个眼神"变成"领悟" |
| **快慢交替** | 制造呼吸感，避免单一节奏的疲劳 | 不要全片同速——慢镜蓄力→快镜爆发→慢镜余韵 |

## 影视表现力技法库

写 prompt 时根据场景需要调用以下技法，提升画面的叙事感和情绪冲击力。**情绪节奏、调性光效、结构化分层**已与上文 **「电影级画面归纳」** 合并对齐；本库侧重 **具体镜头打法与表演句法**，两节一起用。

### 运镜与情绪对应表

每种运镜方式自带情绪暗示，选择运镜前先确定"这个镜头要让观众感受到什么"：

| 运镜 | 情绪效果 | 适用场景 |
|------|---------|---------|
| 缓慢推进 | 逼近、聚焦、压迫、揭示秘密 | 接近角色的弱点/秘密，暴露关键细节 |
| 缓慢拉远 | 疏远、孤立、全貌揭示、收束 | 角色陷入困境，或结尾收束全局 |
| 快速推进 | 冲击、震惊、突然发现 | 恍然大悟，突然看到某物 |
| 跟随运镜 | 代入、紧张、追击 | 跟随角色奔跑或战斗 |
| 环绕运镜 | 审视、展示、英雄高光 | 角色站在中央展示力量/胜利 |
| 手持晃动 | 紧张、混乱、真实感 | 战斗、逃跑、恐慌 |
| 固定不动 | 冷静、控制、客观观察 | 对话、暗中观察、喜剧定格 |
| 仰拍 | 强大、威严、压迫感 | 展现角色支配力、boss登场 |
| 俯拍 | 渺小、脆弱、被审判 | 角色陷入绝境、失败 |
| 倾斜镜头 | 不安、失衡、世界扭曲 | 世界观崩塌、角色精神失控 |

### 反应镜头法则

"角色对事件的反应，往往比事件本身更有力。"

- **先事件后反应**：先用一个镜头展示事件（箭弹飞了），再切到角色面部特写（目瞪口呆）。反应镜头才是真正的情绪炸弹
- **反应比动作重要**：在喜剧中，笑点不是"发生了什么"，而是"角色如何反应"
- **延迟反应**：角色先愣住1-2秒，表情凝固，然后才爆发反应——比立刻反应更有冲击力
- **群体反应放大器**：如果场景中有旁观者，切一个旁观者的震惊反应能成倍放大事件的冲击力
- **沉默反应**：有时候不说话、不动、只是眼神变化，比夸张反应更有力量

### 微表情与神态描写

在prompt中加入面部细节变化的描写，能显著提升角色的表演感：

**眼部变化**：
- 眼神从聚焦缓缓变为失焦（震惊/灵魂出窍）
- 瞳孔猛然缩小（恐惧/不可置信）
- 眼睛猛然睁大眉毛上挑（惊讶/发现）
- 眼角下垂眼皮耷拉（失落/放弃/无力）
- 眼珠缓慢转向一侧斜眼偷看（算计/怀疑/不信任）
- 眼眶微微泛红（感动/委屈/强忍）

**嘴部变化**：
- 嘴角一侧微微上扬（不屑/讥讽/胸有成竹）
- 嘴角微微抽搐（忍住笑/忍住怒/紧张）
- 下意识咬住下唇（犹豫/紧张/害怕）
- 嘴巴缓慢张大合不拢（震惊/崩溃/不可置信）
- 嘴唇紧抿成一条线（决心/愤怒/压抑）

**情绪转换（最出彩的表演时刻）**：
- 不要一步到位，分2-3步完成情绪切换——如"笑容凝固在脸上→眼神逐渐变冷→嘴角缓缓下沉"
- 面部和身体可以不同步——如"嘴上还在笑，但手已经握紧了拳头"
- 情绪递进升级——惊讶→困惑→不可置信→崩溃，每一级之间留停顿

**肢体配合**：
- 手指无意识攥紧拳头（紧张/愤怒/隐忍）
- 肩膀猛然下垂（泄气/放弃/如释重负）
- 身体微微后仰重心后移（抗拒/震慑/不可置信）
- 下意识后退半步（恐惧/本能躲避）
- 手臂无力垂落原本握着的东西掉在地上（震惊到失去力气）

### 动作戏冲击力技法

**冲击帧/定格**：
打击接触的瞬间画面短暂定格——在prompt中写"打击瞬间画面短暂凝固"或"接触一刻定格"。这个技法在日本动画中被广泛使用，能将打击感放大数倍。

**速度线与残影**：
高速运动拖出速度线和残影——在prompt中写"拖出弧形速度线""留下残影轨迹""运动模糊弧线"。动作越快速度线越密越夸张。

**预备蓄力**：
大动作之前必须有蓄力姿态——拳头收到最远再打出、弓弦拉满到极限再松手、起跳前膝盖深弯。蓄力越充分，释放时冲击力越强。"预备动作"和"释放动作"之间的反差 = 力量感。

**环境反应传递力量**：
打击产生的环境连锁反应：地面裂纹扩散、冲击波掀起尘土、周围碎片被气浪弹飞、水面溅起水花、树叶被震落。环境反应的规模 = 力量的大小。不要只写角色动作，要写动作对周围世界的影响。

**对比放大冲击**：
- 快→慢：全速攻击的下一帧切入慢动作 → 冲击感倍增
- 静→动：完全静止画面中突然爆发动作 → 速度感爆炸
- 大→小：全景展示宏大场面后硬切面部特写 → 情绪猛然拉近
- 声→静：激烈音效突然中断变为完全寂静 → 震撼感加倍

### 喜剧节奏技法

**"节拍"停顿（最重要）**：
笑点前留一拍沉默——角色说完关键台词后停顿1-2秒再继续。在prompt中写"说完后停顿一拍""短暂的沉默"。研究表明punchline前的停顿能让笑感提升30%。

**反差与错位**：
- 语气×内容反差：用极其淡定的语气说极其离谱的话（"哦，我顺手补上了"→ 淡定地解决了千年难题）
- 画面×声音反差：紧张BGM配上荒谬画面
- 身份×行为反差：古代英雄使用现代科技

**反应时间 > 事件时间**：
给反应镜头的时间要远多于事件本身——事件发生用0.5秒（箭弹飞），但角色的反应可以持续3-5秒（从愣住到崩溃），让喜剧效果充分展开。

**静态构图 + 留白**：
固定镜头、对称构图、大面积留白 → 让观众自己发现画面中的荒谬之处。越克制的画面越好笑。角色保持不动只有微小变化（如眼珠转动），比夸张动作更有喜感。

**递进式崩溃**：
角色的反应逐级升级而非一步到位——（微笑凝固→眼睛眨了两下→嘴角开始抽搐→突然崩溃大喊）。每一级之间留停顿，让观众跟着角色一起"反应过来"。

### 细节插入镜头

在关键时刻插入物件或身体局部的特写镜头，能无声地传递信息和情绪：

- **道具特写**：手中的武器、桌上的信、掉落的物品——近景特写暗示故事背景和角色状态
- **身体局部**：攥紧的拳头、颤抖的手指、犹豫的脚步、滑落的泪珠——比全身动作更有情绪穿透力
- **环境细节**：飘落的花瓣、滴下的水珠、摇曳的烛火、飞过的鸟——传递氛围、暗示时间流逝或命运转折
- **物品掉落**：武器从手中滑落、弓箭掉在地上、杯子摔碎——一个物品掉落就能传达"一切完了"的信息

### 画面构图法则与情绪（外源交叉·电影构图学系统化）

> **外源交叉**：搜狐·框中框构图法；中国电影网·电影摄影里的透视和构图；绘学霸·电影镜头构图规则；尊正资讯·摄影三分法；韦斯·安德森/库布里克构图分析。

构图不是"画面好看"，是**引导观众视线、传递情绪信息的第四叙事语言**（与景别、光线、色彩并列）。写提示词时构图意识体现在：人物放画面哪里、前景放什么、空间怎么分割。

#### 构图法则速查表

| 构图法则 | 情绪/叙事效果 | 提示词写法 | 典型场景 |
|---------|-------------|-----------|---------|
| **三分法（Rule of Thirds）** | 自然、平衡、专业感 | 「人物位于画面右侧三分之一处」「地平线在画面下方三分之一」 | 通用，几乎所有镜头的默认选择 |
| **中心对称构图** | 权力、秩序、仪式感、庄严、超现实 | 「人物位于画面正中央，左右完全对称」 | 英雄亮相、宫殿/教堂、boss登场、仪式 |
| **偏移/不对称构图** | 失衡、不安、暗藏危机、孤独 | 「人物偏向画面一侧，另一侧大面积留白/暗区」 | 角色内心失衡、预示危险、悬疑 |
| **框中框构图（Frame within Frame）** | 困境、束缚、窥视、隔离、聚焦 | 「镜头透过门框/窗框/拱门拍摄人物，门框形成前景画框」 | 角色被困、偷窥视角、从外向内看 |
| **引导线构图（Leading Lines）** | 纵深感、动感、视线引导 | 「走廊/道路/铁轨/河流从画面近处延伸向远方，人物站在线条的一端」 | 展示方向、暗示命运、增强空间感 |
| **前景遮挡/纵深构图** | 偷窥感、层次感、代入感、神秘 | 「前景是[具体物件]的虚化轮廓，焦点落在中景的人物身上」 | 密谋、躲藏、偷听、增加画面层次 |
| **大面积留白** | 孤独、空旷、沉思、喜剧定格、呼吸感 | 「人物只占画面很小比例，周围是大面积[空间/天空/水面]」 | 孤独、结尾收束、喜剧反应定格 |
| **角色占满画面** | 支配、威胁、存在感爆棚、情绪沉浸 | 「人物面部占满整个画面，只看到脸部和少量背景」 | 威胁、情绪爆发、极致特写 |
| **角色在画面底部** | 被压迫、渺小、无力、环境压迫 | 「人物蜷缩在画面底部，头顶是大面积的[压迫性空间]」 | 绝境、失败、被审判 |
| **对角线构图** | 动感、不稳定、冲突 | 「人物沿画面对角线方向运动/站位」 | 追逐、打斗、心理冲突 |

#### 提示词中的构图执行技巧

1. **用具体物件代替抽象构图词**：AI 不理解"三分法"，但理解"人物站在画面右侧，左侧是大面积的窗户和窗光"
2. **前景遮挡必须写清具体物件**：不写"前景遮挡"，写"前景是课桌椅腿的虚化轮廓" or "前景是半开的门框边缘"
3. **框中框必须写清框的材质**：门框、窗框、拱门、车窗、树枝形成的自然框——写具体
4. **留白用环境词实现**：写大量空间描述（天空、水面、空旷走廊），模型会自动把人物缩小

### 基调反差技法

用户特别提到"画面像悲剧但台词很搞笑"的反差效果。这种**画面情绪×台词情绪**的错位是极其有效的吸引力手段。

#### 反差公式

```
庄重/严肃/悲壮的画面 + 轻松/搞笑/无厘头的台词 = 反差喜感
凄凉/伤感的画面 + 淡定/冷漠/无所谓的台词 = 黑色幽默
紧张/恐怖的画面 + 日常/无聊的台词 = 荒诞喜感
温馨/美好的画面 + 残酷/真实的台词 = 催泪/引人深思
```

#### 视觉执行要点

1. **画面100%认真**：画面越"正经"，反差效果越强。色调、运镜、光影全部按该类型正常配方来做，不要在画面上露出"搞笑"的痕迹
2. **台词100%反转**：台词的情绪和画面的情绪完全反向。画面悲壮→台词轻松。画面紧张→台词无聊
3. **角色表情是关键桥梁**：角色的表情决定反差落在"搞笑"还是"讽刺"——淡定脸+搞笑话=冷幽默；崩溃脸+搞笑话=荒诞喜剧
4. **BGM跟画面走不跟台词走**：背景音乐配合画面的严肃/悲壮基调，不要用搞笑配乐，让音乐和台词形成双重反差

#### 反差效果示例

阿喀琉斯的脚本就是这个技法的典型应用：
- 画面：史诗战场、箭矢飞行、慢镜头打击 → 全部按史诗/热血配方制作
- 台词："哦这个啊？我顺手补上了" → 极度淡定、日常化
- 反差效果：观众预期的史诗悲剧被一句淡定的话消解 → 笑点

#### 可混搭的反差组合

| 画面配方 | 台词/角色行为 | 效果 |
|---------|-------------|------|
| 史诗战场 | 淡定闲聊/吐槽 | 解构经典、消解庄严 |
| 悲壮牺牲 | 突然发现搞了个乌龙 | 荒诞反转 |
| 恐怖黑暗 | 角色完全不怕甚至嫌烦 | 反套路喜感 |
| 浪漫告白 | 对方完全没听懂/跑题 | 尴尬喜剧 |
| 宏大仪式 | 出现低级失误/穿帮 | 解构仪式感 |
| 治愈日常 | 突然插入一句扎心真话 | 治愈中的深刻 |

## 电影化表达要素库（外源共识·检索摘要 2025–2026）

> **用途**：与上文「万能公式」「电影级画面归纳」「影视表现力技法库」「微表情与神态」**叠用**。本条补 **超写实场景、视听叙事、提示词可写清单**，便于写满 Seedream/Seedance 提示词而不堆空洞形容词。  
> **来源交叉**：Seedance 类公式与运镜模块（搜狐/掘金/Apiyi/WenHaoFree 等整理）、AI 视频提示词七要素（Seedance 2.0 博客等）、2025 国产剧集/电影摄影侧 **硬光与光比表意**（新浪/中华网等对《长安的荔枝》《狗阵》等评述中的可迁移技法）。**客户端能力以即梦当前版本为准。**

### 1. 写实场景与环境叙事（画面里「有什么」）

| 写法 | 落 prompt 时怎么做 |
|------|----------------------|
| **前中后景分层** | 各写一层**具体物件或气象**（烟尘、断矛、窗纱、积水），替代「很美」 |
| **材质可读** | 皮肤汗珠/甲片划痕/布褶泥渍/木桌磨损——写实靠**可触摸细节** |
| **天气与时间** | 黄金时刻、蓝调、逆光、雨丝、风卷尘；与**色温**绑定 |
| **环境即剧情** | 道具位置、凌乱度、谁占亮区/暗区，暗示阶层、权力、心理（与下节光影联动） |
| **地域/空间尺度** | 门框台阶作比例参照；远景小人 + 大景 = 史诗感 |

### 2. 光影与情感、剧情（光在「说什么」）

| 概念 | 提示词可写 |
|------|------------|
| **光位表意** | 侧逆光勾轮廓、立体；顶光压眼可显无助/压迫；轮廓光分离主体与背景 |
| **光比与情绪** | 大光比 → 紧张、对峙、秘密；小光比 → 平和、日常、治愈（用「亮部与暗部反差大/柔和」等可拍词） |
| **权力与关系** | 谁落在亮区、谁沉在阴影里 = **可见的权力/心理**，写在主体+场景句里 |
| **硬光/柔光** | 硬光 + 高反差 → 历史质感、暴晒、粗砺真实；柔光 → 唯美、回忆、亲密 |

### 3. 画面表达力（镜头在「看什么」）

| 层级 | 要点 |
|------|------|
| **具体化** | 用**可观察**描写替代「电影感」：色带梯度、影子方向、景深、颗粒、风速 |
| **景别链** | 大远景/全景建立 → 中景叙事 → 近景/特写情绪与信息；**避免**同条里极端特写+大全景矛盾 |
| **运镜节制** | 专业术语 **少量**（推、拉、跟、环绕、荷兰角等），多则失控；中文运镜词与本文运镜表一致 |
| **稳定组合** | 社区常用稳妥结构之一：**缓慢推近 → 轻环绕 → 拉远揭示**（产品/人物展示向，可改编剧情片） |
| **声音三层** | 台词 / 动作与环境音 / BGM 情绪——每条镜头 **突出一层**，写入画面句（Seedance 音画同步） |

### 4. 动作表达（身体在「做什么」）

| 要点 | 写法 |
|------|------|
| **连贯与物理** | 优先「缓慢、连贯、自然」；写清**惯性、反震、碎屑、尘土、衣摆滞后**（与物理感知条目一致） |
| **蓄力与释放** | 大动作前加**预备姿态**，释放后加**环境反馈**，冲击力来自节拍而非形容词 |
| **一镜一主运动** | 同镜少堆多个激烈动词，避免轨迹打架（与稳定性技巧一致） |

### 5. 神态表达（脸在「反应什么」）

| 要点 | 写法 |
|------|------|
| **与微表情章节联动** | 眼、嘴、眉分步变化优于一步到位；**反应镜头时长**常长于事件本身 |
| **光配合脸** | 关键表情处写清**主光方向**是否落在眼窝、半脸阴影，避免「脸好看」空词 |
| **表演分步** | 愣住 → 眼神变 → 嘴角变，用短句时间轴写在 prompt 里 |

### 6. 剧情表达（信息怎么「递进去」）

| 手法 | 提示词侧 |
|------|----------|
| **建立—打破—收束** | 建立镜给足环境；转折用景别或声画陡变；收束用拉远或静场 |
| **悬念与揭示** | 遮挡前景、浅景深移焦、慢推逼近关键物 |
| **对比剪辑感** | 静→动、快→慢、声→静，在单条多镜里用「切换至」拆开写 |

### 7. 自检清单（写毕一条 prompt 快速扫）

1. 场景是否有 **前景/中景/远景** 各至少一项具体物？  
2. 光影是否有 **主光方向 + 冷暖/对比**？  
3. 主体动作是否 **单一主线** + 必要物理/环境反馈？  
4. 脸是否有 **可见微表情或分步**（近景/特写）？  
5. 运镜是否 **一种主运动** + 可执行中文词？  
6. 声音是否 **三层里突出一层**？  
7. 是否避免 **互斥指令**（如全景与眉宇特写塞在同一句无切换）？  
8. 风格锚是否与写实/3D 档位 **无冲突**？

## 视频禁忌

| 禁忌 | 错误写法 | 正确写法 |
|------|----------|----------|
| 古诗词/抽象意境 | 举头望明月 | 一位中国古代男性抬头望向月亮，忧愁氛围，夜晚 |
| 单镜头塞满剧情 | 一个prompt写完一整段故事 | 用「切换至」拆分镜头，或拆为多次生成 |
| 无主语 | 生长，茂盛 | 树木缓慢生长，枝叶变得茂盛 |
| 抽象描述 | 他成长为明君 | 一位穿龙袍的年轻男性坐在金色龙椅上 |
| 模糊形容 | 一个美丽的森林 | 晨雾笼罩的松树林，阳光在露珠上折射出彩虹光斑 |
| 模糊运镜 | 镜头在场景中移动 | 镜头在8秒内缓慢推镜至角色面部特写 |
| 对AI下指令 | 请给我生成、你可以自由发挥 | 直接描述画面内容 |
| 矛盾要求 | 超高速奔跑+极度稳定 | 选择其一：快速奔跑接受运动模糊，或慢速行走保持清晰 |
| 全程同一节奏 | 全部镜头都是5秒中景 | 景别、时长、速度必须有交替变化 |
| 复杂多人互动 | 三个人同时打架 | 拆分为双人互动或依次展示，减少穿模 |
| 堆砌形容词 | 美丽的壮观的令人惊叹的宏伟森林 | 晨雾中的巨型红杉林，树干直径超过两米 |

> **注**：Seedance 2.0 原生支持音画同步，音效描述（如"火焰噼啪作响""金属碰撞声"）应自然融入画面描述中，不再是禁忌。但不要写成独立的音效指令（如"添加雷声音效"），而是融入场景（如"天空乌云密布闪电划过伴随沉闷雷鸣"）。

## 稳定性技巧

- **详细描述 = 稳定输出**：你详细描述了什么，什么就能最大限度保持稳定
- **动作写慢写连续**：慢动作最容易出精品，Seedance 2.0 生成慢速连贯动作最稳定；**燃向、打斗向**不要靠同镜堆动词硬撑，改用上文 **「电影级画面归纳·节奏总纲」** 的短镜/拆条/环境反馈
- **运镜写稳写简单**：复杂运镜交给后期剪辑，单次生成时求稳（单一运镜方式比复合运镜稳定）
- **必加稳定性约束词**：`面部稳定不变形 人体结构正常 动作不僵硬` 是画质保险丝
- **多主体格式**：`主体A + 外观 + 运动，主体B + 外观 + 运动`
- **画风一致性**：每个镜头prompt中都嵌入相同的风格锚
- **对比词强化细节**：如"皮肤白皙但有淡淡雀斑"
- **增加环境细节稳定复杂场景**：如水流、火焰场景需要更多环境信息
- **物理细节锚定动作**：描述具体的物理反应比模糊的动作词更稳定（如"重心前倾脚步加速"比"跑起来"稳定）
