# 即梦画风模版合集（按口令触发）

> **本文件合并自旧 4 份**：`style-realistic-cinematic.mdc`、`style-2d-cel-anime.mdc`、`style-funny-colorpencil-minimal.mdc`、`style-sketch-pencil.mdc`。  
> **定位**：所有「画风模版正文」集中在此；通用技法/方法论见 `jimeng-video-prompt.mdc`；交付硬约束见 `jimeng-core-delivery.mdc`；多段/分镜/自拍/真人过审工作流见 `jimeng-workflows.mdc`。  
> **使用方式**：用户触发某画风口令后，**只调用对应一节**（A/B/C/D/E），同片不混用语义冲突词（例：不要既写「真实毛孔」又写「赛璐璐描边」）。

> **动画角色三视图统一口径**：凡动画类项目（2D、3D、皮克斯式、国漫 3D、卡通、彩绘、线稿等），所有角色参考图一律用同一版式：**左约 1/3 面部特写 + 右约 2/3 正面/侧面/背面全身三视图**。同一段视频里人物、场景、道具必须统一为同一片子的画风、材质和渲染语言；如果参考图来自不同来源，视频关键词必须把最终画风锚写死，避免角色像皮克斯、场景像写实、道具像另一种材质。

> **检索摘要 · 南北朝高僧 / 方丈角色（2026）**：南北朝佛教僧服处在印度袈裟本土化阶段，角色图不要只写“普通僧袍光头”。更稳的历史视觉锚是：内层交领长衫 / 直裰感僧衣，外层披一片田相格纹袈裟（割截衣、百衲衣、水田纹），颜色用灰褐、赤褐、赭褐、暗红褐等“坏色”；可结合北魏至东魏的“褒衣博带式”宽袍垂带、层叠衣褶，或北齐偏圆润温和的面相。儿童向 3D 动画方丈要保留慈祥、可爱和辨识度：圆润额头、下垂长眉、笑眼、圆鼻头、肉肉耳垂、轻微驼背但精神清明、手持念珠或短木杖；避免大众脸、现代罗汉褂、亮黄现代袈裟、过度华丽金纹。

> **检索摘要 · 游戏角色卡牌 / 美食王国五味（2026）**：参考《剑与远征》的塔罗美学、玻璃彩绘、新艺术装饰、派系色彩与身份定位，以及《绝对魔权》的手绘动画、清晰轮廓、强动作张力和环境叙事。做卡牌角色海报时，默认不是证件照：角色必须处在一个正在发生的动作里，且动作动词先行（掀、拖、刺、舀、扯、捧、压、倒、折、封等）；背景和道具必须参与动作，手脚衣摆技能都与食材场景发生真实接触。属性“酸甜苦辣咸”只做系统标签、角标和克制关系，角色锚点必须落到具体食材/菜品（酸菜坛、陈皮、泡椒、海盐、苦瓜、黑芝麻、青梅、醋鱼等）。每张卡先定统一 UI 模板：费用、属性角标、角色名、技能名、底部信息栏、卡框厚度和留白比例固定，只让角色、食材场景和动作变化。角色设计要扣到五官：脸型、眉形、眼裂、眼距、虹膜色、瞳孔大小、高光形状、鼻梁/鼻头、唇形、牙齿或舌尖、表情肌和视线目标都服务性格与故事；默认视线看向道具、敌人或动作方向，只有压迫型角色才直视镜头。画面审美强调角色性、叙事性、人工触感、差异化和价值感，不靠堆特效。

| 项 | 规则 |

## A.3 角色参考图规则（超写实真人专用）

> **方案**：**单张 16:9 三视图总览（`@图片1`）**。三视图覆盖正面/侧面/背面的静态信息，一张图锁全角度。  
> **风险与对策**：社区实测说拼合图 Seedance 容易当杂乱场景处理。对策：三视图 **干净分区、无分割线、统一纯色背景**，降低模型误判为杂乱场景的概率。  
> **与通用三视图的差异**：通用三视图规则的「左 1/3 特写 + 右 2/3 三视图」版式是为卡通/国漫设计的。**超写实真人走本节专用版式**——三等分并排（正面/侧面/背面），无特写分区，每个视角都大且清晰。

## A.4 场景参考图规则（超写实真人专用）

> **结论**：搜索共识是「场景用参考图锁 > 纯文字描述」——Seedance 的 `@` 系统把场景图当锁定元素，多条视频共用同一张环境图时背景不会跳变。  
> **本项目规则**：**视场景复杂度判断**——简单场景靠文字描述即可；复杂场景或多条视频复用时，**出一张 16:9 平面环境图**（不是三视图，是单一视角的完整空间图）。

### A.4.1 何时出场景图、何时不出

| 情况 | 是否出图 | 说明 |
|------|----------|------|
| 纯色背景 / 极简空间（白墙、书桌） | **不出** | 文字写清即可 |
| 同一场景只用 1 条视频 | **看复杂度** | 简单不出，复杂出 |
| 同一场景 **2 条以上** 视频复用 | **出** | 锁背景不跳变 |
| 特定风格空间（民国教室、霓虹街巷） | **出** | 文字难精确描述的空间锁图更稳 |

### A.4.2 Seedream 场景图生图关键词骨架（16:9 平面环境图）

```text
超写实摄影，{场景描述：空间类型+关键陈设+材质}，{时间/天气/光线：如午后阳光透过百叶窗}，{色温与氛围：如暖黄调、柔和自然光}，16:9横构图，无人物无人影空旷场景，无文字无水印，前景{具体物件}中景{具体物件}背景{具体物件}，结构完整透视正确建筑比例合理线条笔直无弯曲变形，2K高清
```

### A.4.3 场景图要点

- **格式**：**单张 16:9 平面图**，一个视角拍全空间。不是三视图、不是全景 360。
- **无人物**：场景图里不放人（人由角色参考图锁）。
- **光色一致**：场景图的 **光照方向与色温** 必须与角色参考图匹配。
- **≥1024×1024 分辨率**：低分辨率场景图会导致视频背景模糊。
- **来源可替**：Seedream 文生图 **或** 用户自备实拍照片上传均可，关键是光色与角色匹配。

### A.4.4 场景图自检

- [ ] 是否为 **单张 16:9 平面图**（非三视图）？
- [ ] 是否 **无人物**？
- [ ] 光照方向与色温是否 **与角色参考图一致**？
- [ ] 是否真的 **需要** 出图（简单场景可否靠文字）？

### A.4.5 场景 360 锁定 / 背景不跳变（外源共识 · 2026）

| 目标 | 做法 |
|------|------|
| 单镜头口播背景稳定 | 用 **1 张空场景图** 锁构图，提示词写「场景环境锁定（参考@图片N），背景与参考图一致不得跳变，固定机位，禁止切镜」 |
| 需要转头/横移/轻微环绕 | 生成同一空间的 **4 张方向图**：正面、左侧、右侧、背面（必要时加俯视/细节），全部无人物、同光色、同陈设；视频提示词写清每张图对应方向 |
| 要真正 360 环绕感 | 优先上传 **空场景 360 横向环绕参考视频**（短、慢、无切镜、无人物）作为 `@视频1`，让 Seedance 参考运镜与空间；再用 `@图片1` 锁人、`@图片2-5` 锁场景方向 |
| 多条视频复用同一场景 | 每条都复用同一组 `@图片N` / `@视频N`，并重复同一套「时间、光位、色温、桌椅、窗户、背景物件」锚点，避免只写「咖啡厅」这种泛称 |

**场景包规则**：场景图必须是 **空场景**，正文写死 `无人物、无人影、无顾客、无服务员、无主角人物、无可读文字、无品牌logo、无水印`。若写「模糊人影」，模型会把人当作场景元素生成出来。

**提示词固定句**：`场景环境锁定（参考@图片2-@图片5），只使用参考图中的空间布局、桌椅位置、窗户方向、光线方向和背景陈设，不新增人物，不改变桌椅数量，不改变窗户位置，不改变吧台和绿植位置，固定机位或严格参考@视频1的慢速环绕运镜，背景稳定不跳变。`

# C · 搞笑彩绘极简（GIF 表情包式 · Seedance 专用）

> **触发**：用户说 **「搞笑彩绘极简」** 或 **「按搞笑彩绘极简模版」** 时。

> **默认**：用户 **不需要** 也不使用单独的「画风参考图 `@图片1`」。**画风锁定** 靠 **一段固定文字** 写在每条 Seedance 提示词 **硬性规则之后、人物与道具 `@` 之前**，避免漂移。  
> **角色与道具** 仍用 **`@图片N` 人物三视图 / 道具图** 锁造型，**`@` 从 `@图片1` 起连续编号**（不与画风图抢序号）。

**可复制文字锚（默认句式，可按项目微调但结构保留）：**

`整片画风为搞笑彩绘极简：2D卡通插画，干净细黑描边，扁平色块上色，肤色与腮红为柔和渐变晕染，阴影很轻，Q版比例，画面干净无噪点，无纸纹无颗粒笔触，无厚涂，无写实皮肤纹理。`

**可选**：用户明确要求 **再加** 画风参考图时，才在 **`## 4.5`** 增加参考图项，并在正文写「画风严格参考@图片某」；**默认不启用**。

## C.2 成片气质：每段≈GIF 表情包

> 用户常希望：**整条或小分段** 像 **聊天软件贴纸 / GIF 表情包**——**画面信息极少**（角色居中、白名单道具、情绪纯色底板），但 **人物表情与身体动作允许、也鼓励夸张**，用来 **直给笑点**，而不是电影化复杂调度。

| 侧面 | 执行 |
|------|------|
| **画** | 背景无叙事负担；**不要** 堆前景层次、环境故事。 |
| **演** | 可写 **瞪眼、歪嘴、石化、汗流、抱头、跪地、双下巴挤出、手指指点、身体后仰前扑** 等 **漫画式夸张**；时间轴内可有 **「定格一拍再回落」** 节奏增强梗感。 |
| **与极简的边界** | 夸张的是 **表演幅度**，不是 **多人物、多道具、多陈设**；未点名物体仍 **禁止**。 |
| **口型** | 若有台词，句末可仍给 **近脸特写** 以保证口型，但 **表演关键词优先写清**。 |

## C.3 适用范围（必读）

- **仅当同时满足**：用户在做 **搞笑彩绘极简** 短片（丑萌 Q 版、2D 彩绘卡通喜剧向等 **用户已说出口或写在项目里的定性**），**且** 用户要求 **极简画面 / 仅出现指定道具 / 禁止 Seedance 乱加东西** 时，助手交付的 Seedance 提示词须遵守本条。
- **与其它规则冲突时**（仅限已声明适用本条的搞笑彩绘极简任务内）：**以本条「能出现的物体」约束为准**；**不减免** 全能参考 **`@`** 与映射的硬要求。

## C.4 核心规定

1. **可视元素白名单**
   - 画面除 **角色**（须 **`@` 人物设定图**，如三视图）外，**仅允许** 用户 **逐条点名** 的 **道具/物件** 入画。
   - 每件道具建议在 **`## 4.5` / `## 7`** 列出 **名称 + 是否用 `@图片N` 锁定**；能上图尽量 **`@`**，锁轮廓与彩绘笔触。

2. **禁止 Seedance 凭空添加**
   - 未点名的：额外陈设、装饰、路人、第二套无关文具、随机书本、板书文字、黑板、窗户绿植、天花板灯、多余桌椅层次等——**不得** 在提示词里用描写 **引导** 模型生成；须用 **正向句** 写清「画面中仅有……」「背景无……」类约束。
   - **禁止** 依赖一长串负面提示替代：仍以 **「仅含白名单角色与道具 + 情绪纯色底板」** 为主句式。

3. **背景默认 → 情绪底色（无纸纹）**
   - 用户要求「像 IP 表情包」且明确 **不要纸纹** 时，背景改为：**在不新增物体与场景陈设的前提下**，用 **纯色底板、轻暗角、聚光圆斑、少量简笔符号** 强化情绪，形成「表情包底板」。
   - **允许的背景表现（不算新增物体）**：纯色底板、轻微暗角、柔和聚光圆斑、少量简笔情绪符号（汗滴、螺旋线、裂纹线、星星、闪光线、乌云线、爱心小点）。
   - **禁止的背景表现（会诱导乱加东西）**：窗、门、课桌台面、地平线、房间透视、道具堆、背景文字弹幕、具体地点装饰。

   **情绪底色参考（交付提示词时每条只选一种写死）**：
   - **沮丧/低落**：偏冷灰蓝纯色底 + 轻暗角 + 头顶小乌云线 + 一两条螺旋线
   - **生气/压迫**：偏暗红棕纯色底 + 放射状怒气线 + 背景对比更强
   - **温柔安慰**：偏暖浅奶黄纯色底 + 柔和光斑 + 细小爱心点点
   - **惊喜/反转**：高亮浅黄纯色底 + 闪光线 + 星星点点聚光

4. **简单风格不等于无 `@`**
   - 极简画面 **仍然** 使用 **全能参考生视频** 与提示词内 **`@图片N`/`@视频N`**（见 **`jimeng-core-delivery.mdc`**）。本条是 **内容极简**，不是 **零参考**。

5. **道具参考图 Seedream 关键词：仅用户点名才写（默认不写）**
   - 适用搞笑彩绘极简时，助手 **不得** 因「可能要锁道具造型」就 **主动** 交付：每张道具的 **Seedream 可复制生图关键词块**、或替用户 **扩张** 一长串「建议先生成这些道具图」的清单。
   - **仅当** 用户在同一次任务里 **用原话** 说明「要给哪些道具出参考图 / 要某某道具的 Seedream 关键词」并 **逐条列出道具名** 时，才为 **点名项** 撰写 Seedream 关键词。
   - Seedance 侧：道具仍通过 **用户已确认的道具白名单 + 自备 `@` 道具图** 或 **提示词内文字形容 + 硬性规则约束** 解决。

## C.5 固定机位 · 表情戏模式（可选子模式）

> 当用户声明 **不需要运镜、不需要多分镜**，以 **表情包式夸张表演**（见 C.2）为主时，在 **搞笑彩绘极简 + 已适用本条** 的任务内启用本节。  
> **不** 改变仓库里其它画风的 **`jimeng-core-delivery.mdc` 全片多镜习惯**——仅本类成片可在项目里 **只交付 `### 镜头01` 一条**（或对话里 **单段 Seedance 全文**），不把「切换至/硬切至/多段时间轴」当作必选项。

| 维度 | 写法 |
|------|------|
| **构图** | 角色 **处于画面中部**（胸像/大半身或全身依需要），**勿写** 推拉摇移跟拍环绕；可写 **固定机位、镜头静止、景别不变**（择一强调即可）。 |

| **分镜** | 整条片可用 **一单条 ≤15s** 或用户拆条导出再剪；多段时按 **梗** 切段，每段一个 **主笑点动作**。 |
| **背景** | 与 C.4 §3 **情绪纯色底板** 一致，可加少量符号点缀，**无** 场景陈设。 |

## C.6 不确定时先问用户（禁止「若」式分支写进交付提示词）

- 道具有无、要不要 `@` 某张图、背景是否加台面等 **未在用户原话里定死** 时：**先向用户问清一句再写提示词**，**禁止** 在交付给用户的 Seedance 正文里写 **「若…」「如果…」「可选」「没有则…」** 等分支。

## D.1 制作侧要点（画面）

| 层级 | 可执行写法 |
|------|------------|
| **线** | 黑色或深灰轮廓线、线条粗细略有变化、手绘感非矢量完美圆角 |
| **明暗** | 平行排线、交叉排线、块面阴影；亮部留白多、暗部线密 |
| **纸** | 米白/浅牛皮纸肌理、轻微颗粒；背景忌高饱和彩色块（除非段落刻意转彩色） |
| **动态** | 原画抓关键姿 + 中割填间隔；数字流程可用洋葱皮对齐 **首尾帧**（常识来自 Pencil2D 等 2D 软件教学） |
| **转描/扫描** | 传统流程里铅笔稿转赛璐璐/数字摄影有过「保线」工序；今可等价为：**高对比干净线稿作 `@` 参考** 锁风格 |

## D.2 表达与节奏（叙事）

- 分镜纸列 **镜号、画面示意、动作、台词、时长、音效**（B 站等平台分镜入门共识）。

- **线稿片**：对比戏可 **少切镜**，用 **固镜 + 面部大特写 + 停顿** 省中割；动作戏 **短镜 + 硬切**，每条里 **一主运动** 防崩。
