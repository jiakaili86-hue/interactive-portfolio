# 2026 IP 展板文字系统参考记录

本轮用于 02-05 展板文字补充的参考方向：

1. 2026 设计趋势强调触感、手工细节、可感知材质，而不是一味光滑。
2. 作品集案例需要讲清项目定位、设计推理和输出系统，不只展示结果。
3. 角色/吉祥物需要从静态形象升级为可表达、可应用、可延展的行为系统。
4. 商业品牌展板的文字应少而准：标题、短说明、关键词、规格标签，而不是大段论文。
5. 深色展板的小字需要提高字号、行距和对比，透明度不能过低。

参考来源见本轮对话中的 Adobe、Creative Bloq、Envato、UXfolio、IxDF、Threerooms、LogoLounge、Noto/Source Han 字体授权等链接。
