## 1. 当前结论

布蜥蜥不是一个单纯的“安静少女 + 守宫宠物”形象，而是一个面向低能量、内向、敏感、不爱无效社交人群的陪伴型少女 IP。

她的核心不是反社交，也不是厌世，而是：保留边界，把真诚留给真正理解自己的人。

小布不是装饰宠物，而是布蜥蜥的情感镜像。它同样因为“不符合大众对可爱宠物的想象”而被误解，但它温和、友好、安静。布蜥蜥在小布身上看到了自己。

### 2.2 角色心理

布蜥蜥不喜欢当下许多“为了利益强行融入”的社交关系。她讨厌表面迎合、强行挤出来的笑脸、为了维系关系而消耗自己。

她选择一个人戴着耳机行动，不是因为她没有感情，而是因为耳机能帮她和不适的关系保持距离。耳机是边界，不是装酷。

她的真诚不是没有，而是不平均分配。她会把最好的反馈留给真正理解她、尊重她、值得她付出的人。

### 2.3 小布的意义

小布是一只小蜥蜴 / 守宫类伙伴。它不像猫狗那样容易被大众天然喜欢，很多人会因为它光滑的皮肤、冷静的神态而害怕它、误解它。

但小布其实温和、友好，对人类没有恶意。布蜥蜥正是因为看见了这一点，才选择收养它，并把它当成最好的朋友。

小布在 IP 中承担三层意义：

| 层级 | 作用 |
|---|---|
| 情感镜像 | 它和布蜥蜥一样，被外表和神态误解 |
| 陪伴对象 | 它是布蜥蜥不用伪装也能相处的朋友 |
| 视觉符号 | 守宫形象能形成独特记忆点，区别于常见猫狗萌宠 IP |

## 3. 核心命题

### 3.1 一句话

布蜥蜥是一位外表冷淡、内心柔软的 INFP 少女；她不愿把真诚浪费在虚伪关系里，只把最好的自己留给真正走近她的人。

### 3.2 情绪价值

这个 IP 想告诉低能量、内向、不爱无效社交的人：

- 不喜欢虚伪关系，不是你的问题。
- 不想强行融入，不代表你冷漠。
- 真诚很珍贵，不需要平均分给所有人。
- 你可以做自己，不必为了异样目光而持续消耗。
- 等真正理解你的人靠近，再把温柔交出去也来得及。

### 3.3 表达边界

布蜥蜥不能被写成：

- 看不起别人
- 厌世
- 反社交
- 只会丧
- 冷暴力
- 自我封闭到拒绝所有关系

她应被写成：

- 有边界感
- 选择性真诚
- 慢热
- 敏感但不脆弱
- 不讨好但有礼貌
- 冷淡外壳下有稳定的温柔

## 5. 当前页面诊断

### 5.1 可保留方向

- 首页封面方向可继续作为第一视觉参考。
- 蓝黑冷调、少量珊瑚红信号色与角色气质基本吻合。
- “角色母版 / 三视图 / 表情 / 周边 / 一天时间线”的页面结构有保留价值。
- 页面已引入本地字体资源，后续可继续使用并加强字重、标题层级与日漫封面式排版。

### 5.2 主要问题

当前页面更像“资产展示页”，还不像“高级商业级 IP 全案”。核心问题是：

- 没有先讲清楚布蜥蜥为什么存在。
- “静音世界”“一天叙事”等概念目前没有完整故事支撑。
- 文案多在解释画面资产，少在传达角色价值。
- 小布的情感功能没有讲出来，只被当作视觉搭档。
- 周边展示还没有从“图片展示”提升到“商品企划”。
- 三视图资产存在后视手部穿帮风险。

### 5.3 需要替换的文案倾向

应减少：

- “世界只静音，梦想仍在继续。”
- “把静音气质拆成可复用视觉部件。”
- “访客一眼看到它从角色走向货架。”

应增加：

- “她不是冷漠，只是不想把真诚浪费在虚伪关系里。”
- “耳机是边界，小布是被允许靠近的朋友。”
- “小布和她一样，被外表误解，却有温和的内里。”
- “把温柔留给真正理解自己的人。”

## 7. 内容语言规范

### 7.1 语气

语气应克制、真诚、有边界感。不要用热血口号，不要用自我感动式鸡汤。

推荐语感：

- “她不是讨厌人群，只是不想在虚伪关系里消耗自己。”
- “她把耳机戴上，不是为了隔绝所有人，而是为了给自己留一点安静。”
- “小布看起来冷，靠近后才知道它很温和。”
- “真诚不需要平均分配。”

### 7.2 禁用倾向

- 不写“社恐怪人”“反社交少女”。
- 不写“逃离人类”“拒绝世界”。
- 不把小布写成猎奇宠物。
- 不把内向写成病态。
- 不把低能量人群写成需要被拯救的人。

## 8. 后续待拍板问题

这些不是阻塞当前重建，但在进入页面和资产重做前需要逐步确认。

1. 布蜥蜥的年龄范围：少女已确认，但是否偏高中生 / 大学生 / 模糊年龄仍待定。
2. “布蜥蜥”名字来源：是昵称、网名、角色名，还是外界给她的称呼。
3. 小布的品种：守宫 / 蜥蜴 / 虚构异宠，需统一。
4. 她的一天发生在哪里：校园、城市、房间、便利店、地铁、天台、独居空间等。
5. 世界观是否现实：现实都市心理 IP，还是略带幻想设定的“静音世界”。
6. 周边主线：治愈陪伴型、潮玩收藏型、文具贴纸型、还是服饰配件型。
7. 表情包九张分别对应哪些情绪场景。
