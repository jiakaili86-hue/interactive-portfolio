# 场景图与小兵动作视频提示词

版本日期：2026-06-09

用途：给 image 生图工具和 Seedance/视频生成工具直接复制使用。

## 统一风格

当前游戏美术方向：

- 4 头身左右美型卡通武侠食物灵。
- 头部约占全身高度 1/4，身体紧凑但不幼稚。
- 干净线稿、平滑上色、低噪点、清爽明亮。
- 武侠动作感，食物元素必须成为角色武器、服装轮廓或阵营徽章。
- 角色和小兵要轮廓清楚，适合在 390x844 竖屏手机画面里缩小显示。
- 不要写实厚涂，不要复杂背景，不要脏乱纹理，不要恐怖血腥。

# 二、小兵动作视频

## 通用视频生成规范

用途：用 Seedance/视频生成工具生成动作视频，再抽帧做 Godot sprite sheet。

建议参数：

```text
时长：4 秒
比例：1:1
分辨率：720p 或 1080p
背景：纯白或纯绿色抠像背景
镜头：固定正交镜头
动作：单一循环动作
角色：居中，完整身体，不能出画
帧率：后期抽 8-12 帧做循环即可
```

视频生成后处理建议：

```text
从 4 秒视频中抽取 8-12 张关键帧
统一裁成 512x512 PNG
清理背景为透明
合成 sprite sheet
Godot 显示尺寸建议 28-44px
```
