# 特效制作规范（VFX Style Guide）

> 来源：2025-2026 检索共识（gamineai 四车道模型 / Toxigon 形状语言 / 机核战斗表现 / Mighty Bear UX / alexrinehart / HAWKED）+ 本项目约束。

## 全局规则

1. **分层（四车道）**：Boss 预警 > 玩家技能 > 命中反馈 > 氛围装饰，对比度按此排序，禁止氛围粒子比预警显眼。
2. **色彩归属**：敌方/Boss 威胁 = 辣红橙系（#d85f3f/#8d3427）独占；玩家技能按流派：酸=草绿、甜=奶金+芝麻黑、苦=墨绿。
3. **每个特效 3-5 色**，硬边清晰（特效边缘 = 玩家感知的作用范围），不做柔光渐变。
4. **节奏**：命中类 0.45s 快进快出；技能类 0.7-0.9s；预警类最长。受击可比攻击大 1.2 倍但更短促。
5. **属性一致**：酸出雾、甜出糯光、苦出藤、辣出火签，禁止混搭违和元素。
6. **占屏克制**：单个特效不超过屏幕 12-18%；范围圈由代码绘制保留，贴图只负责圈内演出。

## 制作流水线（AI 生成）

1. 生成：一张图 2 行 x 4 列 = 8 帧演化，纯色幕布满铺。
   - **绿幕 #00FF00**：红/橙/金/黑/暗色内容。
   - **洋红幕 #FF00FF**：绿色系内容（酸雾、藤蔓），防止内容被抠掉。
2. 抠图：色度键控 + 去溢色（残留像素的幕布色通道压制到其它两通道最大值）。
3. 拼集：按全 8 帧最大内容边长统一缩放，保持帧间大小关系，128px/格 → 1024x128 横向图集。
4. 接入：`_draw_skill_effect` 按特效剩余时间索引帧，范围圈保留，贴图缺失回退程序化绘制。
5. 验收：`--qa-effects-screenshot` 全特效定格截图 + 放大检查边缘无溢色。

## v3 增补（当前线上版本）

1. **法阵透视**：所有地面法阵以约 60° 俯视椭圆绘制（贴合 3/4 视角地面），禁止正圆竖立。
2. **亮度**：抠图后统一向白提亮 20%、整体 alpha×0.85（`process_fx_sheets.py` LIGHTEN/ALPHA_MUL）；游戏内 alpha 调制 `clamp(alpha*3.0,0,1)`，避免双重衰减发灰。
3. **图层**：`GROUND_FX_KINDS`（法阵类）画在地面与角色之间（`_draw_ground_effects`）；shadow 分身与命中火花仍在角色之上。Boss 常驻光环图集随 Boss 绘制，呼吸脉动。
4. **Godot 命令行**：QA 参数必须放在 `--` 之后（`OS.get_cmdline_user_args` 只读分隔符后参数）。

## 兵种精灵流水线（13 兵种全量上线）

1. **视角铁律**：我方兵种 = 背视角（背对镜头向上推进）；敌方兵种 = 正视角（面对镜头向下推进）。
2. **生成**：2x4 八帧、洋红幕 #FF00FF、**提示词写明 NO drop shadow**（源头免阴影，比后处理剥离更干净）；走路用「企鹅摇摆」夸张腿部，攻击默认朝右出手（目标在左时游戏内水平镜像）。
3. **同兵种一致性**：先生成 walk，attack 以 walk 成图作参考图生成，角色造型不漂移。
4. **软边缘抠图**（v2 升级）：按「洋红度」渐变 alpha（LO=40 全保留，HI=130 全透明，线性过渡），边缘半透明像素保留，缩到 30px 后锯齿显著减少；去溢色只作用于边缘带，保护本体紫红色。
5. **统一缩放**：同兵种 walk/attack 共用最大包围盒边长 + 脚底对齐，杜绝切动作时体型跳变；脚底压在代码椭圆影中心（锚点 0.78）。
6. **接入**：`UNIT_SPRITE_DEFS` 数据驱动（图集路径/帧数/fps/hit_time/锚点/镜像开关），新兵种=掉两张图集+一行配置；伤害结算时刻 hit_time 对齐图集「全力攻击帧」（F5≈0.62s）。
7. **出兵预览**：有图集的兵种用半透明走路首帧替代色块圆。
8. **验收**：`--qa-units-screenshot` 全兵种走路+攻击帧全家福（含出兵预览），存 `qa/units_showcase.png`。

## 弹道与技能演出（v4）

1. **远程弹道**：飞行弹形式——亮头（兵种色+白芯）沿弹道推进，短拖尾渐隐，命中点小爆圈；不再画整条静态直线。弹道起点从精灵「出手位」（身体上半部朝目标一侧）射出，不从脚底中心出。
2. **技能 cut-in**：玩家施放技能时，流派色斜切色带从左横扫入场（0.16s 急入 → 0.6s 停留微漂 → 0.27s 加速扫出），内含英雄立绘、技能名大字、英雄名小字；色带不透明度 0.96 压住底层文字。绘制层在特效之上、卡牌 UI 之下。
3. **验收断言**：`skill_cutin_ok`（施法后 cutin 状态激活）。

## Boss 演出 / 死亡表现 / 音效（v5）

1. **Boss 大招 cut-in**：从右侧反向扫入（与玩家镜像），辣红色带 + Boss 立绘靠右排版；触发于技能实际释放瞬间（预警仍提前 3s）。
2. **Boss 蓄力**：预警期 `charge = 1 - 剩余/3`，表现为光环加速增亮、三段「暗红衬底+亮金芯」双层收束弧旋转收拢（半径取光环外圈保证对比度）、白热核心叠在面部上、临爆前 0.8s 身体高频抖动。
2.5a. **Boss 战场形象（v3 全身版，替换 v2 半身）**：用户反馈半身像"头像放大"感奇怪，提供了全身立绘（682×1024 白底带描边）。变化点：
   - **切件改连通块/套索法**：全身图签串与身体接触带复杂（头发、肩甲多点桥接），圆盘切断法试错成本高，改为**多边形套索**沿头发右缘-肩甲上缘空隙走线圈定食物串+火焰，一次成功。锚点 (452,298)。
   - **脚踩火焰座**：全身有腿脚，立绘脚底踩在火环中心稍上（ground+4），前缘火焰舔靴子，火焰座从"遮羞布"变纯王座氛围。
   - **头像统一来源**：HUD/卡牌/cut-in 头像直接从全身图裁 (150,140,450,440)；注意该图脸部位置偏低（眼睛 y≈300），第一次按"头在上半"惯性裁会偏。
   - 元数据见 main.gd `BOSS_ART_*` 常量；切件脚本 `tmp/split_boss_fullbody.py`。
2.5b. **Boss 战场形象（v2 半身立绘切件版，替换 v1 圆球，已被 v3 取代，方法论保留）**：用户否决了画圆+点眼的"球 Boss"。改为复用泡椒火签王原始半身立绘：
   - **抠图**：原图 = 人物（带黑描边）+ 背后红辣椒纹章（无描边）+ 白底；头发与纹章同色无法按颜色区分，**靠描边阻断泛洪**——removable=白色系|纹章红系，从边界泛洪只吃背景，人物内部同色区被描边保护。再清封闭白洞（躯干-手臂间背景，按"面积>800 且质心 y>650"区分于牙齿/高光）+ 连通块清碎屑。脚本 `tmp/process_boss_body.py`。
   - **切件伪骨骼**（`tmp/split_boss_parts.py`）：分段切线把立绘切成「身体主体」（boss_body_main.png）+「火签串」（boss_skewer.png，锚点=签杆从肩甲探出点 (860,550)）。游戏内三重代码动画：身体绕脚底呼吸起伏+轻摆、火签串绕锚点 ±2.6° 慢晃（蓄力加抖）、临爆高频抖动沿用。
   - **贴地火焰座**：半身像没有下半身 → 用 `Transform2D` 把 8 帧火环图集压扁（y×0.36）成与地面平行的椭圆，**前后两半夹住身体**（后半画在身体后、前缘只画贴图下半 region 盖在腰线前），既遮裁切边又替代了"球壳同心圆"光环。蓄力时火环直径+亮度随 charge 增长。
   - **配套特效全部贴地化**：攻击范围圈→0.85 透视椭圆；收束弧→沿地面椭圆轨道（base_xf 下 draw_arc 自动压扁）；白热核心移到胸口纹章；新增 7 颗升腾火星（确定性相位驱动，无需粒子状态）。
   - **坑**：GDScript 全局 `floor()` 返回 Variant，`var x := ... floor(...)` 会推断失败，用 `floorf()`。
3. **死亡消散（v2 烟雾版）**：用户否决了 v1 碎片版（本体虚化缩放放大看着奇怪）。改为：本体**原位原尺寸**前 12% 白闪、25% 内快速淡出（不缩放不下沉）；7 团软边烟雾**错峰绽放**（各团相位差 stagger），膨胀 + 外漂 + 上升 + sin 包络渐隐；烟雾色 = 深灰混 30% 本体色（**背景浅米色，烟雾必须偏深灰才有对比度，浅灰会隐形**）；地面淡环。时长 0.9s。烟雾基元 = 程序生成 64px 径向渐隐圆贴图（`_build_smoke_puff_texture`，draw_circle 硬边画不出软烟）。QA 定格技巧：`time/max_time` 等比放大 10 倍，进度比例不变但能扛住启动慢帧不被耗尽。
4. **音效（v7 网游低沉风，替换 v6 数字音）**：v6 的 Digital 系采样（pepSound/powerUp/lowThreeTone）被用户否决——"游戏机感"，要求**低沉打击感 + 网游角色技能攻击味**。素材源改为 RPG Sound Pack by artisticdude（OGA，CC0）+ Kenney Impact/Interface（CC0），经 `tmp/import_sfx.py` 处理：解码 → 掐静音 → **降调 10%~25% 低沉化**（重采样法）→ **多层混音** → 峰值归一化 → 16bit/44.1kHz wav（共 26 个文件）：

| 事件 | 素材与处理 | 变体数 |
|---|---|---|
| attack_melee | 挥砍 whoosh（×0.9 降调）+ 重拳 thud（×0.8 降调，延迟 50ms 入）**双层混音** | 5 |
| attack_ranged | 挥掷 whoosh ×0.82 降调 | 3 |
| hit | 轻碰撞 ×0.75 降调变闷 | 3 |
| death | 黏液 squish ×0.85 降调（食物角色"噗叽"，配烟雾消散） | 3 |
| deploy | 软质闷响 ×0.85 | 3 |
| skill | 重金属板撞击 ×0.6 深降调打底 + 法术吟唱 ×0.88 铺面**双层混音**（威胁感 = 低频 + 起音瞬态），音量 -5dB | 2 |
| boss_warning | 金属鸣响 ×0.8 降调（不祥钟声） | 1 |
| boss_skill | 重锣 ×0.85 + 低频巨人吼 ×0.75 衬底**双层混音** / 纯锣 | 2 |
| victory / defeat | 拨弦 jingle（基频轨迹分析：上行=胜 / 下行=败），非芯片音 | 各1 |
| click | 标准 UI click | 2 |

   接入规则不变：8 路播放器池、同名 60ms 冷却、随机音高 ±6%。验收断言：`sfx_events_loaded=11/11`、`sfx_variants_total=26`。
5. **音效选型方法论（可复用）**：① 不能试听时用频谱/基频分析代替耳朵——jingle 用自相关法测基频轨迹判断上行（胜利感）/下行（失败感）；② 采样必须掐头部静音，否则打击感延迟；③ 源音量参差，统一峰值归一化后再用 volume_db 配平；④ 同事件至少 3 变体随机轮换，单一采样重复播放是"廉价感"主因；⑤ **"低沉打击感"= 降调（重采样 0.75~0.9）+ whoosh/thud 双层混音**，纯电子合成音（laser/powerUp/pep 类）容易出"游戏机感"，写实拟音（拳、锣、布、金属）才是网游味；⑥ 截图定格 QA 的特效要把 time/max_time 等比放大，防启动慢帧耗尽。

## 兵种 sprite 风格统一 pass（v2，2026-06-12）

> 用户定调：低细节、线条流畅、上色平滑、低噪点、干净、无多余杂色。重做目标 = 缩到 ~30px 仍剪影清晰。

- **重做名单**：糯米团（sesame_dough）、糯影分身（sesame_shadow）、盐粒卒（salt_grunt），各 walk + attack 两套 8 帧图集；其余兵种完成度在线不动。
- **生成口径**：2 行×4 列网格、洋红幕 #FF00FF、同尺寸同角色、粗深色描边 + 平涂赛璐璐 + 单层阴影；我方背视角、攻击侧视朝右（flip_attack 镜像）。提示词加 "bold thick outline / flat cel shading / minimal detail / clean vector-like coloring / no noise, no stray colors"。
- **流水线**：`tmp/process_unit_sheets_v2.py`（洋红抠图→剥手绘阴影→全帧统一包围盒→8x1 横向 256px 图集）。深色本体兵种（糯影）跳过暗色碎片清理，防误删烟雾尾。
- **对比度补救**：白色/淡色本体（盐粒卒）抠图后程序化加 7px 深青灰外描边（#344A5E，再加 2px 半透明羽化），缩小后约 1px，米色战场上不再"看丢"。
- **工程提醒**：替换 assets 下 PNG 后必须先跑 `Godot --headless --path 项目 --import` 刷新导入缓存，再跑 QA 截图，否则游戏仍用旧贴图。
