# 英雄卡立绘提示词模版（B 版 · 少年武侠 / 锁定稿）

> 用途：生成并替换游戏内三张英雄卡立绘（`assets/heroes/hero_pickle_3x4.png` / `hero_sesame_3x4.png` / `hero_bitter_3x4.png`）。
> 锁定于 2026-06-14。参考图见同目录 `hero_card_ref_tu1.png`（即「图1」：绿黄瓜双截棍少年）。

---

## 0. 铁律（每次出英雄卡提示词都必须遵守）

1. **用游戏内现有名称与兵种/技能去设计角色**，不要凭空换主题、不要重命名。三英雄身份取自 `scripts/main.gd` 的 `hero_defs`：
   - 酸 = **酸菜坛灵**（兵：酸叶兵/酸菜医者/坛卫；技：开坛酸雾·酸叶护阵·发酵增援）→ 坛＋酸菜叶＋酸雾
   - 甜 = **黑芝麻糯影灵**（兵：糯米团/芝麻影/甜糯卫；技：糯影分身·甜糯结界·芝麻夜雨）→ 黑芝麻飞镖＋糯米团＋影分身
   - 苦 = **苦瓜藤师**（兵：苦芽兵/苦藤卫/老藤兵；技：苦藤缠绕·清苦压制·老藤守门）→ 苦瓜＋藤鞭＋藤甲
2. **五官、脸型、道具逐项写死**——禁止「五官精致 / 眼睛明亮 / 造型干净 / 漂亮」这类泛词。要像真的在画画：脸型、眉形、眼形+眼线+睫毛+虹膜色+瞳孔大小、鼻形、唇形+表情、痣/刺青等记号、发色+发型+发束方式、武器材质+纹理+结构，全部具体。
3. **画质/风格词可保留**（平涂赛璐璐、清晰黑线稿、低噪点、无杂色、纯白背景）——这些是技术约束，不算泛词。
4. **画幅 3:4 竖版**、纯白背景便于抠图、角色全身居中、不能出现卡牌文字/水印。
5. **性别按英雄分别定**（当前：酸=少年[即图1]、黑芝麻=影系少女、苦瓜=少年；可整体或单个翻转）。
6. 生成后流程：用户出图 → 我裁 3:4 / 去背补白底 / 对齐卡面尺寸 → 放入 `assets/heroes/` → 跑 QA 看卡面。
7. **设计角色要有「心意」**：每个角色的**年龄段、性格、背景故事、特色**都要铺开、彼此拉开差异，不要全是同龄同性格的好看皮。整队（含后续新增主角）的年龄要覆盖童年/少年/青年/中年/老年等不同段位；性格、出身、说话方式、战斗气质各不相同。人设要能对应其玩法定位（铺场/刺客/控制/治疗/重装等）。
8. **头身统一、造型简洁、上色干净**：
   - 全队头身比统一在 **约 4~4.5 头身**，差距别拉大（孩童最多略矮到 ≈4，长辈 ≈4.5）；**年龄靠脸型/五官/体态/发色区分，不靠拉长或缩短身体**。
   - **禁止堆料**：主武器 ＋ 至多 1~2 件标志配饰即可，**不堆挂件、不挂一串杂物、不加多余碎细节**；服装造型简洁。
   - **线条流畅、平涂平滑、颜色干净、无杂色**；每个角色**限 3~4 个主色**，烟/雾/光画成干净云气而非脏块。
   - 「逐项写死五官」与「禁止堆料」并不冲突：五官/脸型/主武器要具体，但配饰与装饰要克制。
9. **画风锚定＝参考图（图1），且图1＝约20岁青年的基准**：
   - 所有英雄卡须**严格模仿图1的整体刻画**——赛璐璐平涂、柔和阴影过渡、干净利落黑线、低噪点、干净配色、约4.5~5头身写意比例、健康肤色质感与画面氛围；**仅人物设定/建模不同**，其余刻画一致。
   - 把图1人物当作**约20岁青年**的样貌基准。其它年龄段以此为参照：孩童＝比基准明显年幼（脸更圆、眼更大、个头略小）、中年＝比基准更成熟魁梧、老年＝比基准苍老。**不是把所有人都画成20岁，也不要把基准误当成15~16岁小孩**。
   - 第一队（酸/甜/苦）即青年段，以图1≈20岁为基准：酸≈20 / 甜≈18 / 苦≈22。

## 3. 角色设定档（年龄 / 性格 / 背景 / 特色）

> 第一队三主角，均为青年段（以图1≈20岁为基准）：酸≈20 / 甜≈18 / 苦≈22。大跨度年龄（童/中/老）由第二队承担。

### ① 酸菜坛灵（酸 · 约20岁青年 · 谋略/腹黑担当）
- **玩法定位**：铺场群攻（酸叶兵）＋治疗（酸菜医者）＋召唤重装坛卫——不靠硬刚、靠「布局发酵」，越拖越强，天然契合谋士。
- **性格**：城府深的青年谋士，狡黠、爱卖关子、嘴上从不吃亏；表面笑眯眯，心里一本账；信「急酸不如慢沤」。
- **背景**：百年酸菜老坛里「沤」出来的坛灵。酸菜要慢慢发酵才入味，他也把打仗当腌一坛好酸菜——讲火候、等时机，把局势「沤」到对自己有利才出手。满窖坛罐是他埋下的棋子，「发酵增援」是早布好的后手，酸雾与护盾都是拖时间、乱敌阵的算计。最爱看对手被自己慢慢「酸」软。
- **特色**：总眯着眼、一抹胸有成竹的坏笑；说话慢条斯理爱设套；把战场当一坛待发酵的酸菜，身上的发酵气泡＝他正在「酝酿」。**主武器是青瓷酸菜坛**——挑准时机开坛放酸雾乱阵、召坛卫、泼酸汁，一坛全是算计，不抡棍硬刚。

### ② 黑芝麻糯影灵（甜 · 约18岁少女 · 沉静反差担当）
- **玩法定位**：影分身（糯影）＋结界治疗（甜糯）＋飞镖夜雨（持续伤害）——刺客／诡术型，昼伏夜出。
- **性格**：寡言冷静、外冷内软，话少却把最甜的默默留给同伴；笑点很低但永远绷着脸。
- **背景**：糯米与黑芝麻在月下舂捣千百次凝成的影灵。生于一家深夜才开张的芝麻糖铺，影子比她本人更早学会做活，于是"分身"成了天赋。她怕白天的喧闹，只在夜里出手——技能都带"夜""影"。甜，是唯一能让她表情松动的东西。
- **特色**：影分身替她社交与作战，本体躲在后面；受伤会渗出芝麻糊般的黑；安静到能听见糯米发酵的声音。武器：黑芝麻飞镖。

### ③ 苦瓜藤师（苦 · 约22岁青年 · 沉稳大哥担当）
- **玩法定位**：藤蔓缠绕控制＋清苦削弱＋召唤藤墙守门——控制／防守型，护队压场。
- **性格**：清冷寡淡、话不多但有担当，苦口婆心式的温柔；信"良药苦口"。
- **背景**：在终年云雾的苦瓜崖上随老藤修行的年轻藤师，师父是一株成精的百年老藤（即"老藤守门"召唤物）。他以苦瓜与藤入药，走到哪治到哪，却总被人嫌药苦、话也苦。其实最心软，宁可自己尝尽苦，也要给旁人留一口回甘。
- **特色**：颈侧藤蔓刺青随情绪生长；听得懂藤蔓"说话"；"苦后回甘"是他的信条（削弱敌人、守护友军）。武器：苦瓜青藤鞭。

## 4. 第二队主角（草案 · 名称/数值待用户拍板）

> 味系补「咸 / 鲜 / 麻」凑齐五味＋（辣＝Boss）。年龄铺开（咸中年 / 鲜老年 / 麻孩童），但**头身比全队统一在约 4~4.5 头身、差距别拉大**（孩童≈4、中年/老年≈4.5），年龄靠脸型五官体态区分而非拉长身体。画风按 §0/§1：线条流畅、平滑上色、颜色干净、无杂色、造型简洁不堆料、每人限 4 主色。

### ④ 盐卤腊味将（咸 · 约45岁中年硬汉 · 重装镇守担当）
- **玩法定位**：重装坦克/前排硬控——高血厚甲、嘲讽吸收、范围减速（盐卤腌住敌人），越扛越硬。
- **性格**：豪爽耿直、护短、嘴硬心软；信「咸能锁住鲜，扛住了就赢」。
